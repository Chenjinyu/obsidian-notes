# 多倫多工程職缺追蹤

## 使用方式

- [JOBS.md](JOBS.md)：累積職位總表。JC 修改「我的選擇」與「我的備註」；自動更新必須保留這兩欄。
- `weekly/YYYY-MM-DD.md`：每次找到的職位、核查來源和技能差距，保留歷史快照。
- `monthly/YYYY-MM.md`：合併該日曆月的所有週報，去重並整理 JC 的選擇。

「我的選擇」可填：待選、保留、略過、已申請。新職位預設待選；不替 JC 做保留或申請決定。略過的職位保留歷史但不再次推薦，除非 JC 更改選擇。已關閉的職位標記關閉，不刪除。

## 篩選要求

- 僅 Toronto / GTA 的 Backend、Full Stack、Platform 工程職位；遠端職位須允許住在 Toronto 並從加拿大受聘。
- 優先 Staff / Senior Staff / Principal；Senior 或技術 Lead 須符合薪資與工作內容。
- 自 2026-10-19 起，目標加拿大年度基本薪資 CAD 250,000 及以上，無上限；公布完整上下限、幣別、地點與職級。下限達標標「全區間達標」；僅上限達標可列但標「僅上限達標／需爭取」，不保證 offer。加拿大 base 未公開者僅列薪資待確認，不用美國薪資換算。bonus、股票／RSU、sign-on、搬遷補助與加拿大適用福利另外記錄，未知標未公開／待確認。
- 公司須成熟、有可核查的規模與營運歷史；排除小公司與創業初期公司。「成熟」不代表保證穩定。
- JC 是目前住在美國、願意搬到 Toronto 的美國公民；公司未公開承諾 sponsorship 不影響職位納入，依下方 CUSMA 規則另列雇主配合狀態，未知不當成不符合。不能因國籍或 offer 推定工作許可必定獲批。
- 公司官網／官方 ATS 職缺頁為主要來源；核查職缺仍開放、勤務地、CAD 基本薪資、所需技能和搬遷／工作許可條件。
- 不湊數；沒有符合條件職位就如實記錄。薪資未公開但極高匹配、可能達標者僅列「待確認候選」，不能混入已確認達標的推薦。

## CUSMA／境外聘用初篩（2026-10-23 更新）

2026-10-23 CUSMA 搜尋規則：JC是目前住美國、願搬Toronto的美國公民。先按技術匹配、成熟公司、加拿大基本薪資CAD250,000+與Toronto地點篩選，不把公司公開承諾sponsorship當成納入前提。未提sponsorship、不提供LMIA、或籠統「no visa sponsorship」均不得自動排除；後者保留並標「CUSMA雇主配合待確認」，在recruiter screen再釐清是否拒絕LMIA還是拒絕任何工簽協助。只有明確要求已持加拿大工作權且不配合任何所需工簽手續，或明確拒絕境外候選人／搬遷而與JC情況衝突時，才按此條件排除；僅現居當地要求須辨別是入職前可搬遷還是不可接受境外申請。CUSMA適用資格仍須依實際職責及學歷／專業資格核查，不因美國國籍、Software Engineer職稱或offer推定自動符合。符合CUSMA專業人士類別時可免LMIA，但仍須取得所需工作許可；雇主通常需Employer Portal提交聘用資料、支付CAD230合規費並提供offer of employment number（依當時官方規定及例外核查）。雇主配合未知不降低技術／薪資匹配排序，不得把「未確認工簽協助」寫成「不符合／無法申請」。報告分別列薪資／技術匹配與CUSMA雇主配合（已確認／待確認／明確拒絕），附依據。申請表應按目前實際工作權與問題定義如實回答，不自動替JC勾選已獲加拿大工作權。禁止自動申請或聯絡公司。下次搜尋重新檢視歷史上僅因sponsorship／LMIA資訊未知或籠統拒絕而排除的職缺；不改寫歷史快照，不覆寫JC略過／保留等選擇。
