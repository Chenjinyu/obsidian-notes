# Daily Interview Questions

Archive daily interview questions, JC's answers, and the explanations developed during practice.

## Session folders

Use `YYYY-MM-DD_topic-slug/` so the date and subject are visible before opening the folder, for example `2026-11-11_protobuf-grpc-compatibility/`. Use the **America/Chicago** date and keep the exact ISO creation timestamp and timezone in each note's frontmatter. Reuse the existing topic folder and session notes when continuing the same discussion.

Create one descriptive Markdown file per topic. Each note should contain:

- The interview question or discussion question. Preserve an available original prompt; label a summarized or reconstructed prompt clearly.
- JC's answer or understanding, kept separate from corrections and the suggested answer.
- Definitions, comparisons, concrete examples, and relevant follow-up questions.
- A short natural English interview answer for practice, with Chinese explanations where useful.
- Official references and links to related notes.

Use real dates for the existing spaced-repetition fields (`sr-due`, `sr-interval`, `sr-ease`), together with a real creation timestamp. Do not use unresolved template placeholders. Mark clarification-only sessions accurately rather than claiming a full mock interview was completed.

## Review workflow

Prepare new notes and discussion updates on a branch from `master`, then open a pull request for JC to review. Keep work in this folder unless JC requests another location. Wait for JC's review before merging.
