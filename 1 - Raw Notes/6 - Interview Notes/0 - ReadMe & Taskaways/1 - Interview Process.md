# Content

It varies by company, but here's a general breakdown:

---

**Typical Interview Process:**

| Stage | Type                       | Rounds | Focus                            |
| ----- | -------------------------- | ------ | -------------------------------- |
| 1     | **Resume Screen**          | 1      | HR reviews resume, no interview  |
| 2     | **Phone/HR Screen**        | 1      | background, salary, availability |
| 3     | **Technical Phone Screen** | 1      | easy/medium coding question      |
| 4     | **Coding Interview**       | 2-4    | data structures, algorithms      |
| 5     | **System Design**          | 1-2    | architecture, scalability        |
| 6     | **Behavioral**             | 1-2    | teamwork, conflict, leadership   |
| 7     | **Hiring Manager**         | 1      | culture fit, role expectations   |

---

**By company tier:**

```
Tier 1 (FAANG/MANGA — Google, Meta, Amazon, Apple, Netflix):
  Total rounds: 5-7
  ├── 1 HR screen
  ├── 1 technical phone screen
  ├── 3-4 coding rounds (onsite/virtual)
  ├── 1-2 system design rounds
  └── 1 behavioral round

Tier 2 (Uber, Airbnb, Stripe, LinkedIn):
  Total rounds: 4-6
  ├── 1 HR screen
  ├── 1 technical phone screen
  ├── 2-3 coding rounds
  └── 1 system design round

Tier 3 (Mid-size startups):
  Total rounds: 3-4
  ├── 1 HR screen
  ├── 1-2 coding rounds
  └── 1 culture fit / hiring manager

Tier 4 (Small startups):
  Total rounds: 2-3
  ├── 1 casual chat
  ├── 1 take-home project or live coding
  └── 1 culture fit
```

---

**Coding interview difficulty by tier:**

```
FAANG:       Leetcode Medium/Hard — must be very fast and clean
Tier 2:      Leetcode Medium — optimized solutions expected
Tier 3:      Leetcode Easy/Medium — correctness over optimization
Tier 4:      Real world problems, take-home projects
```

---

**Tips:**

- FAANG coding rounds are usually **45 minutes** per round — practice speed
- System design is usually required for **mid-senior level** roles
- Behavioral rounds use **STAR format** (Situation, Task, Action, Result)
- Total process typically takes **2-6 weeks** from first contact to offer
