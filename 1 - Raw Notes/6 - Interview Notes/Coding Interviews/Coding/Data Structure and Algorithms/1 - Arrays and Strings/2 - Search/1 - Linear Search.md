# Linear Search - Is normally I do the serach

The Linear Search algorithm searches through an array and returns the index of the value it searches for.
```python
```python
def linear_search(arr, targetVal):
    for i in range(len(arr)):
        if arr[i] == targetVal:
            return i
    return -1
```
