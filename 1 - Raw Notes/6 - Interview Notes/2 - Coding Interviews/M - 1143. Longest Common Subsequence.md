# Problem
Given two strings `text1` and `text2`, return _the length of their longest **common subsequence**._ If there is no **common subsequence**, return `0`.
A **subsequence** of a string is a new string generated from the original string with some characters (can be none) deleted without changing the relative order of the remaining characters.
- For example, `"ace"` is a subsequence of `"abcde"`.
A **common subsequence** of two strings is a subsequence that is common to both strings.

**Example 0:**
**Input:** text1 = "abcde", text2 = "edcab" 
**Output:** 2  
**Explanation:** The longest common subsequence is "ab" and its length is 2.

**Example 1:**
**Input:** text1 = "abcde", text2 = "ace" 
**Output:** 3  
**Explanation:** The longest common subsequence is "ace" and its length is 3.

**Example 2:**
**Input:** text1 = "abc", text2 = "abc"
**Output:** 3
**Explanation:** The longest common subsequence is "abc" and its length is 3.

**Example 3:**
**Input:** text1 = "abc", text2 = "def"
**Output:** 0
**Explanation:** There is no such common subsequence, so the result is 0.

**Constraints:**
- `1 <= text1.length, text2.length <= 1000`
- `text1` and `text2` consist of only lowercase English characters.

class Solution:
	"""
	❌ This solution also gets the common charts, its not getting the subsequance charts. 
	"""
    def longestCommonSubsequence(self, text1: str, text2: str) -> int:
        str1_len = len(text1) # row
        str2_len = len(text2) # col

        max_match = 0
        if not str1_len or not str2_len: return max_match
        for i in range(str1_len):
            match_list = []
            for j in range(str2_len):
                if text1[i] == text2[j]:
	                # only equals, but it does not know the previous subsequence.
                    match_list.append(text1[i])

            max_match = max(max_match, len(match_list))

        return max_match

class Solution:
	"""
	Time Complexity: O(m * n)
	Space Complexity: O(m * n)
	Button-Up: Tabulation
	"""
    def longestCommonSubsequence(self, text1: str, text2: str) -> int:
	    # looks them as the grid, row and col
        rows, cols = len(text1), len(text2)

        # dp[0][cols] and dp[rows][0] = 0 are the base case
        dp = [[0] * (cols + 1) for _ in range(rows + 1)]

        for i in range(1, rows + 1):
            for j in range(1, cols + 1):
                if text1[i-1] == text2[j-1]:
                    dp[i][j] = dp[i-1][j-1] + 1
                else:
                    dp[i][j] = max(dp[i-1][j], dp[i][j-1])

        return dp[rows][cols]
```

# Optimization
# form the two methods, it only needs prev row and curr row. 
# same like example in [[Coding/Data Structure and Algorithms/7 - Greedy/Greedy|Greedy]]

class Solution:
    """
    Time Complexity: O(cols * rows)
    Space Complexity: O(cols)
    """
    def longestCommonSubsequence(self, text1: str, text2: str) -> int:
        rows, cols = len(text1), len(text2)

        prev = [0] * (cols + 1)
        curr = [0] * (cols + 1)

        for i in range(1, rows + 1):
            for j in range(1, cols + 1):
                if text1[i-1] == text2[j-1]:
                    curr[j] = prev[j-1] + 1
                else:
                    curr[j] = max(prev[j], curr[j - 1])
            prev = curr
            curr = [0] * (cols + 1)

        return prev[cols]

```
