# Content

These are major dynamic programming families.
Once you recognize the pattern family, many LeetCode problems become much easier because the recurrence structure repeats.

# 1. Knapsack DP

This family is about:
> choosing items under constraints
Usually:
- maximize value
- minimize cost
- reach target sum
- limited capacity

The name comes from:
> putting items into a backpack with limited capacity

# Classic Knapsack
Suppose:
```python
weights = [1,3,4,5]
values  = [1,4,5,7]
capacity = 7
```
Choose items maximizing value.

# Core DP idea
State often looks like:
```python
dp[i][c]
```
Meaning:
> best answer using first i items  
> with capacity c

# Typical recurrence
For each item:
```python
take it
or
skip it
```

# Famous knapsack-style problems
## Subset Sum
Can numbers sum to target?
## Partition Equal Subset Sum
Split into equal sums.
## Coin Change
Minimum coins.
## Target Sum
Ways to assign +/-.
## Ones and Zeroes
2D knapsack.

# Mental pattern
Knapsack usually involves:
```python
decision:
take or not take
```

# 2. LIS (Longest Increasing Subsequence)
This family is about:
> finding increasing relationships

Classic problem:
Find longest increasing subsequence.
Example:
```python
[10,9,2,5,3,7,101,18]
```

LIS:
```python
[2,3,7,101]
```
length = 4.

# Core DP idea
Often:
```python
dp[i]
```
means:
> longest increasing subsequence ending at i

# Transition
Look backward:
```python
if nums[j] < nums[i]
```
then:
```python
dp[i] = max(dp[i], dp[j] + 1)
```

# LIS family problems
## Longest Increasing Subsequence
## Russian Doll Envelopes
## Maximum Length of Pair Chain
## Longest String Chain
## Wiggle Subsequence

# Mental pattern
LIS problems usually involve:
```python
build optimal sequence ending at current position
```

# 3. Partition DP
This is the hardest family.
Pattern:
> split array/string into groups

and optimize something.

# Core idea
Try every split point:
```python
for k in range(...)
```
Then combine:
```python
current partition
+
optimal future partitions
```

# Example
## Split Array Largest Sum
Try every first split.
## Palindrome Partitioning II
Try every substring split.
## Matrix Chain Multiplication
Try every multiplication order.

## Burst Balloons
Choose final balloon.
# Common recurrence shape
```python
dp(left, right)
```
or:
```python
dp(index, partitions_remaining)
```

# Mental pattern
Partition DP usually means:
```python
enumerate all possible split positions
```
This is why it often becomes:
```python
O(n²)
or
O(n³)
```

# Easy way to distinguish them
# Knapsack
Ask:
```python
Should I take this item?
```
Usually:
- capacity
- sum
- count
- choices

# LIS
Ask:
```python
Can current element extend previous sequence?
```
Usually:
- increasing
- ordering
- chaining

# Partition DP
Ask:
```python
Where should I split?
```
Usually:
- intervals
- segmentation
- partitions

# Why this matters
Top candidates do NOT memorize every problem.
They classify problems into DP families.
Then reuse templates.
When experienced people see:
```python
split array into k groups
```
they immediately suspect:
```python
partition DP
or
binary search on answer
```
That pattern recognition is the real skill.
