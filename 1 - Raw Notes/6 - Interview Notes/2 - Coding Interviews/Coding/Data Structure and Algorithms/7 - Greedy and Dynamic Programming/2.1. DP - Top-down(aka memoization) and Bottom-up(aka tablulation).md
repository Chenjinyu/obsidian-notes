# Content

Bottom-Up cannot memorize the old data, because the lower data won't be called when the n value goes up.
But top-down can memorize the old data, because f(5) will use f(3) and f(4), the f(3) has f(2) also the f(4) has f(2).

After we calculate F(2)F(2), let's store it somewhere (typically in a hashmap), so in the future, whenever we need to find F(2)F(2), <p style="color:green">we can just refer to the value we already calculated instead of having to go through the entire tree again</p>
```txt
**memoizing** a result means to store the result of a function call, usually in a hashmap or an array, so that when the same function call is made again, we can simply return the **memoized** result instead of recalculating the result.
```
