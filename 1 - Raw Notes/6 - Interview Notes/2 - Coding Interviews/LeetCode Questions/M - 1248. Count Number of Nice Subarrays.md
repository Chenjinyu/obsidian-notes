# Problem

```text
Given an array of integers `nums` and an integer `k`. A continuous subarray is called **nice** if there are `k` odd numbers on it.
Return _the number of **nice** sub-arrays_.

**Example 1:**
**Input:** nums = [1,1,2,1,1], k = 3
**Output:** 2
**Explanation:** The only sub-arrays with 3 odd numbers are [1,1,2,1] and [1,2,1,1].

**Example 2:**
**Input:** nums = [2,4,6], k = 1
**Output:** 0
**Explanation:** There are no odd numbers in the array.

**Example 3:**
**Input:** nums = [2,2,2,1,2,2,1,2,2,2], k = 2
**Output:** 16

**Constraints:**
- `1 <= nums.length <= 50000`
- `1 <= nums[i] <= 10^5`
- `1 <= k <= nums.length`
```

# Step 2 - Try Brute Force First to help you understand the structure of the problems
```python
class Solution:
    def numberOfSubarrays(self, nums: List[int], k: int) -> int:
        ans = 0
        for i in range(len(nums)):
            odd_count = k # has to re-assign, because the k is global, if using k to count, the decreased k won't charge back in the next outer for loop
            for j in range(i, len(nums)):
                if nums[j] % 2 == 1:
                    odd_count-= 1
                if odd_count == 0: ans += 1
                elif odd_count < 0: break
        return ans
```

# Step 3 - Think about Optimization
the solution could be sliding window, but, need to handle the combination in the subarray, as i wrote above with "~~strikethrought~~".
then, the sliding window needs to have left, mid and right. the mid uses to loop back

```python
class Solution:
    def numberOfSubarrays(self, nums: List[int], k: int) -> int:
        res, odd = 0, 0
        l, m = 0, 0
        for r in range(len(nums)):
            if nums[r] % 2 == 1:
                odd += 1
			
			# the left and mid pointers are only moved when odd greater than k.
            while odd > k:
                if nums[l] % 2 == 1: odd -= 1
                l += 1
                m = l

            if odd == k:
                while nums[m] % 2 == 0:
                    m += 1
                res += (m - l) + 1

        return res
```
### Step 3: Takeaways
1. the checking/collecting results should be after all states have been checked. 
```text
	Stabilize(稳定) your state first, then check/collect results.
```
#### General mental model for sliding window
```
1. expand right         → add new element
2. shrink left          → fix violations (stabilize)
3. check/collect        → harvest result from valid window
```
#### Always think: **"is my window valid before I collect from it?"** If any step can invalidate the window, it must run before harvesting.

```python
from collections import defaultdict
class Solution:
    def numberOfSubarrays(self, nums: List[int], k: int) -> int:
        bit_prefix_sum = defaultdict(int)
        bit_prefix_sum[0] = 1
        ans = curr_prefix_sum = 0
		bit_nums = [elem % 2 for elem in nums]
        for i in range(len(bit_nums)):
            curr_prefix_sum += bit_nums[i]
            gap = curr_prefix_sum - k
            if gap in bit_prefix_sum:
	            ans += bit_prefix_sum[gap]
            bit_prefix_sum[curr_prefix_sum] = bit_prefix_sum.get(curr_prefix_sum) + 1
        return ans
nums = [2,2,2,1,1,2,1,1]
k = 3
output = 5
```
