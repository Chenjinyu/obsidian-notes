# Problem
You are a hiker preparing for an upcoming hike. You are given `heights`, a 2D array of size `rows x columns`, where `heights[row][col]` represents the height of cell `(row, col)`. You are situated in the top-left cell, `(0, 0)`, and you hope to travel to the bottom-right cell, `(rows-1, columns-1)` (i.e., **0-indexed**). You can move **up**, **down**, **left**, or **right**, and you wish to find a route that requires the minimum **effort**.
A route's **effort** is the **maximum absolute difference** in heights between two consecutive cells of the route.

Return _the minimum **effort** required to travel from the top-left cell to the bottom-right cell._

**Example 1:**
![200](https://assets.leetcode.com/uploads/2020/10/04/ex1.png)
**Input:** `heights = [[1,2,2],[3,8,2],[5,3,5]]`
**Output:** 2
**Explanation:** The route of [1,3,5,3,5] has a maximum absolute difference of 2 in consecutive cells.
This is better than the route of [1,2,2,2,5], where the maximum absolute difference is 3.

**Example 2:**
![200](https://assets.leetcode.com/uploads/2020/10/04/ex2.png)
**Input:** heights = [[1,2,3],[3,8,4],[5,3,5]]
**Output:** 1
**Explanation:** The route of [1,2,3,4,5] has a maximum absolute difference of 1 in consecutive cells, which is better than route [1,3,5,3,5].

**Example 3:**
![200](https://assets.leetcode.com/uploads/2020/10/04/ex3.png)
**Input:** heights = [[1,2,1,1,1],[1,2,1,2,1],[1,2,1,2,1],[1,2,1,2,1],[1,1,1,2,1]]
**Output:** 0
**Explanation:** This route does not require any effort.

**Constraints:**
- `rows == heights.length`
- `columns == heights[i].length`
- `1 <= rows, columns <= 100`
- `1 <= heights[i][j] <= 10^6`

```python
class Solution:
    def minimumEffortPath(self, heights: List[List[int]]) -> int:
	    """
	    Dijkstra is using the heapq to short the min value in the node. 
	    and find the effortest path.
	    Time Complexity: O(m * n * log (m * n ))
	    """
        rows, cols = len(heights), len(heights[0])
        directions = [(1,0), (-1,0), (0, 1), (0, -1)]
        visited = set()
        heap = [(0,0, 0)] # effort, row, col, 
        target = (rows - 1, cols - 1)
        while heap: # O(n * n)
            eff, r, c = heapq.heappop(heap) # O(log n )
            if (r, c) == target:
                return eff
            if (r, c)  in visited:
                continue
            
            visited.add((r, c))
            
            for dr, dc in directions: # O (4)
                nr, nc = dr + r, dc + c
                if (
                    0 <= nr < rows 
                    and 0 <= nc < cols
                    and (nr, nc) not in visited
                ):
	                # the max effort for current node, but in the heapq(priority queue) will pick(pop) up the min one every time.
	                # so in the each step of path traverse, the max effort added to current node,
	                # but every time the heapq will pop up the node with min effort.
	                # so, effort should be first in list so that the heapq uses it to sort.
                    effort = max(eff, abs(heights[nr][nc] - heights[r][c]))
                    heapq.heappush(heap, (effort, nr, nc)) # O (log n )
        
        return 0
```

```python
class Solution:
	"""
	Binary Search + BFS
	Time complexity: O(m * n log(10 ^ 6))
	which will a little slower than Dijkstra + heapq solution
	"""
    def minimumEffortPath(self, heights: List[List[int]]) -> int:
        rows, cols = len(heights), len(heights[0])
        directions = [(1,0), (-1,0), (0,1), (0,-1)]

        def can_reach(limit):
            # BFS/DFS to check if target is reachable with effort <= limit
            visited = set()
            visited.add((0, 0))
            queue = deque([(0, 0)])
            while queue:
                r, c = queue.popleft()
                if (r, c) == (rows-1, cols-1):
                    return True
                for dr, dc in directions:
                    nr, nc = r + dr, c + dc
                    if (
                        0 <= nr < rows
                        and 0 <= nc < cols
                        and (nr, nc) not in visited
                        and abs(heights[nr][nc] - heights[r][c]) <= limit
                    ):
                        visited.add((nr, nc))
                        queue.append((nr, nc))
            return False

        left, right = 0, 10**6  # effort range 0 to max possible
        while left < right:
            mid = (left + right) // 2
            if can_reach(mid):
                right = mid   # valid, try smaller effort
            else:
                left = mid + 1  # not reachable, need more effort

        return left
```
