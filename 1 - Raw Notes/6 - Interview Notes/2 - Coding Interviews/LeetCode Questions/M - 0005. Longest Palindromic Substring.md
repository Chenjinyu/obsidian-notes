# Problem
Given a string `s`, return _the longest_ _palindromic_ _substring_ in `s`.
**Example 1:**
**Input:** s = "babad"
**Output:** "bab"
**Explanation:** "aba" is also a valid answer.

**Example 2:**
**Input:** s = "cbbd"
**Output:** "bb"

**Constraints:**
- `1 <= s.length <= 1000`
- `s` consist of only digits and English letters.

```python
class Solution:
	# ❌, it only can get the commom characters. 
    def longestPalindrome(self, s: str) -> str:
        s = list(s)
        reverse_s = set(list(s[::-1]))
        ans = reverse_s.intersection(set(s))
        return "".join(ans)
```
