I was running the BFS from every 1 cell, there is no visited check. in the outer for loop, the time complexity is: O(m * n)
and inside of while: also is O(m * n) in the worse case, the while will loop all nodes with all directions.

🔥 The right idea (this is the key insight)
Intead of `From each 1, find nearest 0`
Flip it: `From all 0s, spread distances outward. in other words, get the distance from the previous node which already has, and +1 to get your current node's distance

This turns it into multi-source BFS
- Time: O(m * n)
- Memroy: O(m * n) (optimal)
  
# Single-source (your current approach)
for each 1-cell:
    BFS outward until you hit a 0    ← redundant work, paths overlap

# Multi-source
seed queue with ALL 0-cells at dist=0
BFS outward together, stamping dist on each 1 when first reached  ← each cell touched once  
  
```

# Problem
Given an `m x n` binary matrix `mat`, return _the distance of the nearest_ `0` _for each cell_.
The distance between two cells sharing a common edge is `1`.

**Example 1:**
![200](assets/M%20-%200542.%2001%20Matrix/file-20260408032937336.png)
**Input:** mat = [[0,0,0],[0,1,0],[0,0,0]]
**Output:** [[0,0,0],[0,1,0],[0,0,0]]

**Example 2:**
![200](assets/M%20-%200542.%2001%20Matrix/file-20260408032954971.png)
**Input:** mat = [[0,0,0],[0,1,0],[1,1,1]]
**Output:** [[0,0,0],[0,1,0],[1,2,1]]

**Constraints:**
- `m == mat.length`
- `n == mat[i].length`
- `1 <= m, n <= 104`
- `1 <= m * n <= 104`
- `mat[i][j]` is either `0` or `1`.
- There is at least one `0` in `mat`.
**Note:** This question is the same as 1765: [https://leetcode.com/problems/map-of-highest-peak/](https://leetcode.com/problems/map-of-highest-peak/description/)

class Solution:
	"""
	Memory Limit Exceeded
	the time complexity: O(n ^ 2 * m ^2)
	- outer loop: O(mn) - iterates every cell
	- each BFS: O(mn) - in the worse case, visits every cell before finding a 0 
	  
	this solution:
	- does not reuse results, but each BFS recomputes distance already found before.
	"""
    def updateMatrix(self, mat: List[List[int]]) -> List[List[int]]:
        if not mat: return []
        row_len = len(mat)
        col_len = len(mat[0])
        def bfs(row, col):
            queue = deque([(row, col, 0)])
            distance = 0
            nonlocal row_len, col_len
            while queue:
                r, c, dist = queue.popleft()
                directions = [(1,0), (-1,0), (0,1), (0, -1)]

                for dr, dc in directions:
                    nr, nc = dr + r, dc + c

                    if 0 <= nr < row_len and 0 <= nc < col_len:
                        if mat[nr][nc] == 1:
                            queue.append((nr, nc, dist + 1))
                        else: 
                            return dist + 1
        
        ans = [[0] * col_len for _ in range(row_len)]
        for r in range(row_len):
            for c in range(col_len):
                if mat[r][c] == 1:
                    ans[r][c] = bfs(r, c)
        
        return ans
```
