# Problem
Given an `m x n` binary matrix `mat`, return _the distance of the nearest_ `0` _for each cell_.
The distance between two cells sharing a common edge is `1`.

**Example 1:**
![200](assets/M%20-%200542.%2001%20Matrix/file-20260408032937336.png)
**Input:** mat = [[0,0,0],[0,1,0],[0,0,0]]
**Output:** [[0,0,0],[0,1,0],[0,0,0]]

**Example 2:**
![200](assets/M%20-%200542.%2001%20Matrix/file-20260408032954971.png)
**Input:** mat = [[0,0,0],[0,1,0],[1,1,1]]
**Output:** [[0,0,0],[0,1,0],[1,2,1]]

**Constraints:**
- `m == mat.length`
- `n == mat[i].length`
- `1 <= m, n <= 104`
- `1 <= m * n <= 104`
- `mat[i][j]` is either `0` or `1`.
- There is at least one `0` in `mat`.
**Note:** This question is the same as 1765: [https://leetcode.com/problems/map-of-highest-peak/](https://leetcode.com/problems/map-of-highest-peak/description/)

```python
class Solution:
	"""
	Memory Limit Exceeded
	the time complexity: O(n ^ 2 * m ^2)
	- outer loop: O(mn) - iterates every cell
	- each BFS: O(mn) - in the worse case, visits every cell before finding a 0 
	  
	this solution:
	- does not reuse results, but each BFS recomputes distance already found before.
	"""
    def updateMatrix(self, mat: List[List[int]]) -> List[List[int]]:
        if not mat: return []
        row_len = len(mat)
        col_len = len(mat[0])
        def bfs(row, col):
            queue = deque([(row, col, 0)])
            distance = 0
            nonlocal row_len, col_len
            while queue:
                r, c, dist = queue.popleft()
                directions = [(1,0), (-1,0), (0,1), (0, -1)]

                for dr, dc in directions:
                    nr, nc = dr + r, dc + c

                    if 0 <= nr < row_len and 0 <= nc < col_len:
                        if mat[nr][nc] == 1:
                            queue.append((nr, nc, dist + 1))
                        else: 
                            return dist + 1
        
        ans = [[0] * col_len for _ in range(row_len)]
        for r in range(row_len):
            for c in range(col_len):
                if mat[r][c] == 1:
                    ans[r][c] = bfs(r, c)
        
        return ans
```

## Solution 1 - Multi-Source BFS
This solution BFS works like Dijkstra with weight = 1
🌊 Think of it like water spreading, the lands are surrounding by water, the closest water will reach the land first.
•  All zeros are water sources
•  All other cells are dry land (∞ = dry)
•  Water spreads outward, filling land with increasing distance values

🔥 Key Insight
`inf` means “unvisited”
A real number means “distance already computed”
This is the same idea as:
•  Dijkstra initialization
•  Bellman‑Ford initialization
•  BFS distance array initialization
#### Waves
```text
  Wave 1
∞   1   ∞           2   1   2
1   0   1    ->     1   0   1
∞   1   ∞	        2   1   2
```

🌟 What “relaxation” means
Relaxation = trying to improve the known distance to a node.
In other words: “If I found a shorter path to this neighbor, update it.”
> It’s literally the act of _relaxing_ (reducing) the distance estimate.

🧠 Why is it called “relaxation”?
Historically, the idea is:
•  You start with a “tight” (bad) upper bound on distance (like ∞)
•  You “relax” that bound by lowering it whenever you find a better path
```python
from collections import deque
from typing import List

class Solution:
    def updateMatrixMultiSource(self, mat: List[List[int]]) -> List[List[int]]:
	    """
	    Time Complexity:
	      Each cell is popped from the queue once → O(1)
	      Each cell checks 4 neighbors → O(1)
	      ⭐ Final Time Complexity: O(rows * cols)  # This is optimal — you cannot do better than touching each cell once.
	    Space Complexity: 
	      - BFS queue, In the worst case, the queue may hold many cells, but never more than the grid size: O(rows * cols)
	      - The matrix itself, You modify mat in place, so no extra matrix is created.
	      ⭐ Final Space Complexity: O(rows * cols)
	    """
        rows, cols = len(mat), len(mat[0])
        queue = deque()
        # step 1: Initialize multi-source queue with all 0s, mark 1s as infinity
        for r in range(rows):
            for c in range(cols):
                if mat[r][c] == 0:
                    # the reason to append 0, is because to leverage the 0 as the entry to check the min distance for each layer nodes.
                    queue.append((r, c))
                else:
                    # inf marked as unvisited. will use to compare with previous layer's node
                    mat[r][c] = float('inf')

        # step 2: Multi-source BFS
        direcitons = [(1,0), (-1,0), (0,1), (0,-1)]

        while queue:
            r, c = queue.popleft()

            for dr, dc in directions:
                nr, nc = dr + r, dc + c

                if 0 <= nr < rows and 0 <= nc < cols:
                    # relaxation step
                    # moving from a cell to its neighbor costs 1 step, so, the neighbor layer supposed to have +1
                    # the queue will pop all 0 nodes surrounds the 1 nodes, and choose the min distance.
                    if mat[nr][nc] > mat[r][c] + 1:
                        mat[nr][nc] = mat[r][c] + 1
                        queue.append((nr, nc)) # only this path works, then add the next layer candidates to queue

        return mat
```

## Solution 2 - DP approach no BFS  (even more optimized)
👉 No queue  
👉 O(1) extra space  
👉 Very strong interview signal
```python
class Solution:
    def updateMatrixDP(self, mat: List[List[int]]) -> List[List[int]]:
        rows, cols = len(mat), len(mat[0])
        
        # First pass (top-left → bottom-right)
        for r in range(rows):
            for c in range(cols):
                if mat[r][c] != 0:
                    top = mat[r-1][c] if r > 0 else float('inf')
                    left = mat[r][c-1] if c > 0 else float('inf')
                    mat[r][c] = min(top, left) + 1
        
        # Second pass (bottom-right → top-left)
        for r in range(rows-1, -1, -1):
            for c in range(cols-1, -1, -1):
                if mat[r][c] != 0:
                    bottom = mat[r+1][c] if r < rows-1 else float('inf')
                    right = mat[r][c+1] if c < cols-1 else float('inf')
                    mat[r][c] = min(mat[r][c], bottom + 1, right + 1)
        
        return mat
```
