# Problem
You have a graph of `n` nodes. You are given an integer `n` and an array `edges` where `edges[i] = [ai, bi]` indicates that there is an edge between `ai` and `bi` in the graph.

Return _the number of connected components in the graph_.

**Example 1:**
![200](assets/M%20-%200323.%20Number%20of%20Connected%20Components%20in%20an%20Undirected%20Graph/file-20260407015517871.png)

**Output:** 2

**Input:** n = 5, edges = [[0,1],[1,2],[2,3],[3,4]]
**Output:** 1

**Constraints:**
- `1 <= n <= 2000`
- `1 <= edges.length <= 5000`
- `edges[i].length == 2`
- `0 <= ai <= bi < n`
- `ai != bi`
- There are no repeated edges.

## 1. Graph DFS Solution
```python
class Solution:
    def countComponents(self, n: int, edges: List[List[int]]) -> int:
        adj = defaultdict(list)
        # It's sparse graphs, so build adjacency list. 
        # (adjacency matrix cannot reduce the time complexity, that's why in the real world, use the adjacency list much more than adjacency matrix)
        for a, b in edges:
            adj[a].append(b)
            adj[b].append(a)  # undirected, both directions
        # rest of the logic is the same with 547. Number of Provinces
        visited = set()
        ans = 0

        def dfs(node):
            stack = [node]
            visited.add(node)
            while stack:
                curr = stack.pop()
                for neighbor in adj[curr]:
                    if neighbor not in visited:
                        visited.add(neighbor)
                        stack.append(neighbor)

        for i in range(n):  # range(n) not adj.keys(), because isolated nodes have no edges
            if i not in visited:
                dfs(i)
                ans += 1

        return ans
```

## 2. Union-Find(Disjoint Set Union, DSU) Solution
This Union‑Find version is:
•  Faster for sparse graphs
•  Cleaner for connectivity problems
•  A must‑know pattern for interviews

```python
class Solution:
    def countComponents(self, n: int, edges: List[List[int]]) -> int:
	    """
	    Time Complexity: O(n + edges * a(n))
		    - O(n) to initialize parent and rank arrays
		    - O(edges x a(n)) to process each edge with union()
	    where a(n) is the inverse Ackermann funciton - practically constant
	    
	    Space Complexity: O(n) for parent and rank arrays
	    """
	    # the number of nodes
        parent = list(range(n)) # if number n of node = 5, return [0,1,2,3,4]
        rank = [1] * n   # or size array

        def find(x):
            # path compression
            # when parent[x] = x, means the x is itself's parent. 
            # after calling union, one example: parent[2] = 0
            # when next loop, which includes 2 again, actually it compares with root 0
            if parent[x] != x:
                parent[x] = find(parent[x])
            return parent[x]

        def union(a, b):
            rootA, rootB = find(a), find(b)
            if rootA == rootB: # for the union,
                return 0  # return 0 means there is no two nodes unioned. no merge happened

            # union by rank (attach smaller tree under larger)
            if rank[rootA] < rank[rootB]:
                parent[rootA] = rootB
                rank[rootB] += rank[rootA]
            else:
                parent[rootB] = rootA
                rank[rootA] += rank[rootB]

            return 1  # merge happened

        # Start with n components
        components = n

        # For each edge, union the two nodes
        for a, b in edges:
            components -= union(a, b)

        return components
```

```text
Without rank:          With rank:
1→2→3→4→5             1
(chain, depth n)      /|\
                     2 3 4
                     (flat, depth log n)
```

Path compression
```text
Before find(5):        After find(5):
1                      1
└─2                   /|\ \
  └─3                2 3 4 5   ← all point directly to root. so the find is O(1)
    └─4
      └─5 # the find is O(log n) amortized
```
### 3. Union-First with out rank
```python
class Solution:
    def countComponents(self, n: int, edges: List[List[int]]) -> int:
        """
        Time Complexity: O(n + edges * log n) with path compression
	        - O(n) to initialize parent array
	        - O(edges * log n) to process each edge with union()
	        (slightly worse without rank optimization)
	        
        Space Complexity: O(n) for parent array only
        """
        parent = list(range(n))
		
		def find_without_path_compression(x):
			while parent[x] != x:
				x = parent[x] # just walks up, no rewiring.
			return x
		
        def find(x):
	        # without rank, O( log n) per operation
	        # 1 → 2 → 3 → 4 → 5(root)
	        # after find() — every node on the path points directly to root:
			# 1 → 5(root)
			# 2 → 5(root)
			# 3 → 5(root)
			# 4 → 5(root)
            # with path compression(压缩)
            if parent[x] != x:
                parent[x] = find(parent[x])
            return parent[x]

        def union(a, b):
            rootA, rootB = find(a), find(b)
            if rootA == rootB:
                return 0  # no merge happened

            # Simple union - just attach rootB under rootA
            # <- with rank, then, the rank logic will lives here.
            parent[rootB] = rootA # without rank, just attach arbitrarily
            return 1  # merge happened

        # Start with n components
        components = n

        # For each edge, union the two nodes
        for a, b in edges:
            components -= union(a, b)

        return components
```
