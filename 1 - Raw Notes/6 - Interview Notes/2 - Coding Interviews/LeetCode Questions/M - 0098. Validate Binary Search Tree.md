# Problem
Given the `root` of a binary tree, _determine if it is a valid binary search tree (BST)_.
A **valid BST** is defined as follows:
- The left subtree of a node contains only nodes with keys **strictly less than** the node's key.
- The right subtree of a node contains only nodes with keys **strictly greater than** the node's key.
- Both the left and right subtrees must also be binary search trees.

**Example 1:**
![200](assets/M%20-%200098.%20Validate%20Binary%20Search%20Tree/file-20260401032637117.png)
**Input:** root = [2,1,3]
**Output:** true

**Example 2:**
![200](assets/M%20-%200098.%20Validate%20Binary%20Search%20Tree/file-20260401032656688.png)
**Input:** root = [5,1,4,null,null,3,6]
**Output:** false
**Explanation:** The root node's value is 5 but its right child's value is 4.

**Constraints:**
- The number of nodes in the tree is in the range `[1, 104]`.
- `-231 <= Node.val <= 231 - 1`

### 1. Recursive 
```python
# Definition for a binary tree node.
# class TreeNode:
#     def __init__(self, val=0, left=None, right=None):
#         self.val = val
#         self.left = left
#         self.right = right
class Solution:
    def isValidBST(self, root: Optional[TreeNode]) -> bool:
	    """
		    Time complexity: O(n)
		    Space: O(1)
	    """
        self.prev = None
        def inorder_dfs(node):
            # reached the tree's leaf's child. there is no node to violate any BST rule.
            # An empty subtree is trivially(微不足道地) valid.
            #     5
            #  /    \
            # 3      7
            # None None <- these are valid "empty BSTs", not violations
            if not node: return True 

            # propagate up
            # i was using inorder_dfs(node.left), the return never propagate up
            if not inorder_dfs(node.left): return False 

            if self.prev is not None:
                if self.prev >= node.val: return False
            self.prev = node.val

            return inorder_dfs(node.right)
        
        return inorder_dfs(root)
```

### 2. Stack
```python
# Definition for a binary tree node.
# class TreeNode:
#     def __init__(self, val=0, left=None, right=None):
#         self.val = val
#         self.left = left
#         self.right = right
class Solution:
	"""
	Time Complexity: O(n), space worse case: O(n)
	this solution is slower than the recursive one.
	"""
    def isValidBST(self, root: Optional[TreeNode]) -> bool:
        prev = None
        curr = root
        stack = []

        while stack or curr:
            if curr: # in the if branch, it's push left nodes. the curr initializes the None
                stack.append(curr)
                curr = curr.left
            else: # in the else branch, read curr node, and push right node
	            # in the else branch, it has the node from left, to compare with node, it has node to compare with right.
                curr = stack.pop()
                if prev is not None:
                    if prev >= curr.val: return False
                prev = curr.val
                curr = curr.right
        return True

```
