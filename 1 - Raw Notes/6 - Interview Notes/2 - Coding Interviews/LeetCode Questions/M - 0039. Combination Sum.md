# Problem
Given an array of **distinct** integers `candidates` and a target integer `target`, return _a list of all **unique combinations** of_ `candidates` _where the chosen numbers sum to_ `target`_._ You may return the combinations in **any order**.

The **same** number may be chosen from `candidates` an **unlimited number of times**. Two combinations are unique if the frequency of at least one of the chosen numbers is different.

The test cases are generated such that the number of unique combinations that sum up to `target` is less than `150` combinations for the given input.

**Example 1:**
**Input:** candidates = [2,3,6,7], target = 7
**Output:** `[[2,2,3],[7]]`
**Explanation:**
2 and 3 are candidates, and 2 + 2 + 3 = 7. Note that 2 can be used multiple times.
7 is a candidate, and 7 = 7.
These are the only two combinations.

**Example 2:**
**Input:** candidates = [2,3,5], target = 8
**Output:** `[[2,2,2,2],[2,3,3],[3,5]]`

**Example 3:**
**Input:** candidates = [2], target = 1
**Output:** []

**Constraints:**

- `1 <= candidates.length <= 30`
- `2 <= candidates[i] <= 40`
- All elements of `candidates` are **distinct**.
- `1 <= target <= 40`

# Step 3 - Think about Optimization
Compare with other backtrack, eg., [[M - 0077. Combinations]], the start increase to look for the next possible answer.
for below case, the start does not increase in recursive backtrack, until the remain <= 0, then the i index in the for loop move to next one.


```python
class Solution:
	"""
	Reuse allowed.
	Depth depends on target.
	Worst-case complexity becomes exponential in target:
	Time and Space Complexity: O (N ^ (T/M))
	The max depth of the tree is T/ M - using smallest number repeatedly until we exceed target. 
	N = Number of Candidates
	T = Target
	M = Minimum candidate. 
	"""
    def combinationSum(self, candidates: List[int], target: int) -> List[List[int]]:
        ans = []

        def backtrack(start, remain, path):
            if remain == 0: # equals to target. 
                ans.append(path.copy()) # O(n), but only remain == 0
                return

            if remain < 0: # exceeded target
                return 

            for start_idx in range(start, len(candidates)):
                cand = candidates[start_idx]

                path.append(cand) # choose
                backtrack(start_idx, remain - cand, path) # reuse allowed by keeping start_idx as the same, until remain <= 0, then start_idx moves to next.
                path.pop() # undo.
            
        backtrack(0, target, [])
        return ans
        
# []
# ├── 2
# │   ├── 2
# │   │   ├── 2
# │   │   │   └── remain = 1
# │   │   └── 3
# │   │       └── remain = 0 => [2,2,3]
# │   └── 3
# ├── 3
# ├── 6
# └── 7 => [7]
```
