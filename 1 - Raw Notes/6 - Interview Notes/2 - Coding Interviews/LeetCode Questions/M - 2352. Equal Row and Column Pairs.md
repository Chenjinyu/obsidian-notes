# Problem
Given a **0-indexed** `n x n` integer matrix `grid`, _return the number of pairs_ `(ri, cj)` _such that row_ `ri` _and column_ `cj` _are equal_.
A row and column pair is considered equal if they contain the same elements in the same order (i.e., an equal array).

**Example 1:**
**Input:** grid = [[3,2,1],[1,7,6],[2,7,7]]
**Output:** 1
**Explanation:** There is 1 equal row and column pair:
- (Row 2, Column 1): [2,7,7]

**Example 2:**
**Input:** `grid = [[3,1,2,2],[1,4,4,5],[2,4,2,2],[2,4,2,2]]`
**Output:** 3
**Explanation:** There are 3 equal row and column pairs:
- (Row 0, Column 0): [3,1,2,2]
- (Row 2, Column 2): [2,4,2,2]
- (Row 3, Column 2): [2,4,2,2]

**Constraints:**
- `n == grid.length == grid[i].length`
- `1 <= n <= 200`
- `1 <= grid[i][j] <= 10^5`

# Step 3 - Think about Optimization
```python
class Solution:
    def equalPairs(self, grid: List[List[int]]) -> int:
	    """
	    Time complexity: O(n^2) in second for loop.
	    the zip is lazy in python, it returns an iterator, not a list.
	    """
        row_count = defaultdict(int)
        ans = 0
        for row in grid:
	        # has to be converted tuple, because its immutable, which is allowed to be the dict key
            row_count[tuple(row)] += 1
	    
	    # zip(*grid) lazy - only holds one column in memory at a time. O(n) space.
        for col in zip(*grid):
            col_tuple = tuple(col)
            if col_tuple in row_count:
                ans += row_count[col_tuple]
        return ans
```

## Step 3: Solution 2
```python
class Solution:
    def equalPairs(self, grid: List[List[int]]) -> int:
	    """
	    Time complexity: O(n^2)
	    """
	    # Counter is from collections.is subclass of dict, but it specialized for counting.
	    # The value is always an integer representing the count.
        row_count = Counter(map(tuple, grid))
        return sum(row_count[col] for col in map(tuple, zip(*grid)))
```

# Takeaways
1. Count is subclass from dict, so has the same behavior as defaultdict, only the count's value is integer
2. so there is no exception when you get value from non-existing index. 
3. the key in dict, only accept immutable, tuple, str, int. these are hashable. 

## **`defaultdict` (and all dicts) require keys to be hashable.**
