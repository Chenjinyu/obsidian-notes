# Problem
You are given an `m x n` grid `rooms` initialized with these three possible values.
- `-1` A wall or an obstacle.
- `0` A gate.
- `INF` Infinity means an empty room. We use the value `231 - 1 = 2147483647` to represent `INF` as you may assume that the distance to a gate is less than `2147483647`.
Fill each empty room with the distance to _its nearest gate_. If it is impossible to reach a gate, it should be filled with `INF`.

**Example 1:**
![400](assets/M%20-%200286.%20Walls%20and%20Gates/file-20260410005831435.png)
**Input:** rooms = [[2147483647,-1,0,2147483647],[2147483647,2147483647,2147483647,-1],[2147483647,-1,2147483647,-1],[0,-1,2147483647,2147483647]]
**Output:** [[3,-1,0,1],[2,2,1,-1],[1,-1,2,-1],[0,-1,3,4]]

**Example 2:**
**Input:** rooms = [[-1]]
**Output:** [[-1]]

**Constraints:**
- `m == rooms.length`
- `n == rooms[i].length`
- `1 <= m, n <= 250`
- `rooms[i][j]` is `-1`, `0`, or `231 - 1`.

class Solution:
    def wallsAndGates(self, rooms: List[List[int]]) -> None:
        """
        Do not return anything, modify rooms in-place instead.
        This problem is similar with [[M - 0542. 01 Matrix]]
        
        Time Complexity:
	      Each cell is popped from the queue once → O(1)
	      Each cell checks 4 neighbors → O(1)
	      ⭐ Final Time Complexity: O(rows * cols)  # This is optimal — you cannot do better than touching each cell once.
	    Space Complexity: 
	      - BFS queue, In the worst case, the queue may hold many cells, but never more than the grid size: O(rows * cols)
	      - The matrix itself, You modify mat in place, so no extra matrix is created.
	      ⭐ Final Space Complexity: O(rows * cols)
	      
        """
        rows, cols = len(rooms), len(rooms[0])
        queue = deque()
        # 1. Initial queue with all gates, the gates are the first wave
        for r in range(rows):
            for c in range(cols):
                if rooms[r][c] == 0:
                    queue.append((r, c))

        # waves    
        directions = [(1,0), (-1,0), (0, 1), (0, -1)]
        while queue:
            r, c = queue.popleft()

            for dr, dc in directions:
                nr, nc = dr + r, dc + c

                if 0 <= nr < rows and 0 <= nc < cols:
                    if rooms[nr][nc] != -1 and rooms[r][c] + 1 < rooms[nr][nc]:
                        rooms[nr][nc] = rooms[r][c] + 1
                        queue.append((nr, nc))
                        
        return rooms
