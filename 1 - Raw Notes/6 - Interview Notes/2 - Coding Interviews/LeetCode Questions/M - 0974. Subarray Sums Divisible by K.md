# Problem

Given an integer array `nums` and an integer `k`, return _the number of non-empty **subarrays** that have a sum divisible by_ `k`.
A **subarray** is a **contiguous** part of an array.

**Example 1:**
**Input:** nums = [4,5,0,-2,-3,1], k = 5
**Output:** 7
**Explanation:** There are 7 subarrays with a sum divisible by k = 5:
[4, 5, 0, -2, -3, 1], [5], [5, 0], [5, 0, -2, -3], [0], [0, -2, -3], [-2, -3]

**Example 2:**
**Input:** nums = [5], k = 9
**Output:** 0

**Constraints:**
- `1 <= nums.length <= 3 * 104`
- `-10^4 <= nums[i] <= 10^4`
- `2 <= k <= 104`

```python
from typing import List
from collections import defaultdict
class Solution:
    def subarraysDivByK(self, nums: List[int], k: int) -> int:
        prefix_sum = defaultdict(int)
        prefix_sum[0] = 1
        ans = curr_prefix_sum = 0
        
        for i in range(len(nums)):
            curr_prefix_sum += nums[i]
            # the condition is: (curr_sum - prev_sum) % k = 0
            # which means: curr_sum % k = prev_sum % k
            gap = curr_prefix_sum % k
            if gap in prefix_sum:
	            ans += prefix_sum[gap] # its not necessary to check if the gap in the hashmap, because if not, it returns 0
            prefix_sum[gap] += 1
        return ans
        
```
