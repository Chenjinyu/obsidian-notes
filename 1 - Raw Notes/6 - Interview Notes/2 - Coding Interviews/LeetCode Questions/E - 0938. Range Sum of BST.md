# Problem
Given the `root` node of a binary search tree and two integers `low` and `high`, return _the sum of values of all nodes with a value in the **inclusive** range_ `[low, high]`.

**Example 1:**
![200](assets/E%20-%200938.%20Range%20Sum%20of%20BST/file-20260330235235064.png)
**Input:** root = [10,5,15,3,7,null,18], low = 7, high = 15
**Output:** 32
**Explanation:** Nodes 7, 10, and 15 are in the range [7, 15]. 7 + 10 + 15 = 32.

**Example 2:**
![200](assets/E%20-%200938.%20Range%20Sum%20of%20BST/file-20260330235257948.png)
**Input:** root = [10,5,15,3,7,13,18,1,null,6], low = 6, high = 10
**Output:** 23
**Explanation:** Nodes 6, 7, and 10 are in the range [6, 10]. 6 + 7 + 10 = 23.

**Constraints:**
- The number of nodes in the tree is in the range `[1, 2 * 104]`.
- `1 <= Node.val <= 105`
- `1 <= low <= high <= 105`
- All `Node.val` are **unique**.

# Step 3 - Think about Optimization

### 1. Using dequeue
```python
# Definition for a binary tree node.
# class TreeNode:
#     def __init__(self, val=0, left=None, right=None):
#         self.val = val
#         self.left = left
#         self.right = right
class Solution:
	"""
	wrost case when all nodes in the tree are between low and high.
	on averaage this algorithm will perform better than simply searching all nodes.
	"""
    def rangeSumBST(self, root: Optional[TreeNode], low: int, high: int) -> int:
        queue = deque([root])
        ans = 0
        while queue:
            for _ in range(len(queue)):
                node = queue.popleft()
                if node.val >= low and node.val <= high:
                    ans += node.val

                if node.left and node.val >= low: # should use > i
                    queue.append(node.left)
                if node.right and node.val <= high:
                    queue.append(node.right)

        return ans
```

### 2. Using recursive.
```python
# Definition for a binary tree node.
# class TreeNode:
#     def __init__(self, val=0, left=None, right=None):
#         self.val = val
#         self.left = left
#         self.right = right
class Solution:
    def rangeSumBST(self, root: Optional[TreeNode], low: int, high: int) -> int:
        if not root: return 0
        ans = 0
        if root.val >= low and root.val <= high:
            ans += root.val
        if low < root.val:
            ans += self.rangeSumBST(root.left, low, high)
        if high > root.val:
            ans += self.rangeSumBST(root.right, low, high)

        return ans
```
