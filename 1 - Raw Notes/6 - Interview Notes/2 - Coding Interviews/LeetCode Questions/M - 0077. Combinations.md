# Problem
Given two integers `n` and `k`, return _all possible combinations of_ `k` _numbers chosen from the range_ `[1, n]`.
You may return the answer in **any order**.

**Example 1:**
**Input:** n = 4, k = 2
**Output:** `[[1,2],[1,3],[1,4],[2,3],[2,4],[3,4]]`
**Explanation:** There are 4 choose 2 = 6 total combinations.
Note that combinations are unordered, i.e., [1,2] and [2,1] are considered to be the same combination.

**Example 2:**
**Input:** n = 1, k = 1
**Output:** [[1]]
**Explanation:** There is 1 choose 1 = 1 total combination.

**Constraints:**
- `1 <= n <= 20`
- `1 <= k <= n`

The Time Complexity is k * the total number combination of size k from n numbers: 
![](assets/M%20-%200039.%20Combination%20Sum/file-20260515022028059.png)
```python
class Solution:
	"""
	This pattern is the backtracking classic pattern. 
	The core ideas here are:
	- using for loop with increased start to exclude elem after collected all possibilities. 
		- for example, this case starts at 1
		  - the for loop will move to next, when all backtrack functions return back to the for loop. 
		  - eg. when n = 5, and k =4. 
		    - [1,2,3,4], this one will be returned back to [1,2,3] which is the caller, and then 4 pops out from curr.
		    - the idx from the caller of backtrack(1, []), is still 1.
		    - but from the [1,2,3], the idx is 4 after pop, then the 5 will be push to curr due to the for loop.
		- the idx will move to next, from 1 to 2, only after all backtrack functions return back to the caller when the idx is 1.
		  
	Time Complexity: O(k * C(n, k))
		- The number of subsets: C(n, k)
		  - C(n, k) = Combinations of n! / (k! * (n - k)!)		  
		
	"""
    def combine(self, n: int, k: int) -> List[List[int]]:
        ans = []

        def backtrack(start, curr):
            if len(curr) == k:
                ans.append(curr.copy())
                return

            # the combination starts at 1, and end at n.
            for idx in range(start, n + 1):
                curr.append(idx)
                backtrack(idx + 1, curr)
                curr.pop()

        backtrack(1, []) # the combination starts at 1.
        return ans

```
