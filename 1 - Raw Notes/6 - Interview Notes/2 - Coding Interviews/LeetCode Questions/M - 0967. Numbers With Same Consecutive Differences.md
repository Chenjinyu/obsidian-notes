# Problem
Given two integers n and k, return _an array of all the integers of length_ `n` _where the difference between every two consecutive digits is_ `k`. You may return the answer in **any order**.

Note that the integers should not have leading zeros. Integers as `02` and `043` are not allowed.

**Example 1:**

**Input:** n = 3, k = 7
**Output:** [181,292,707,818,929]
**Explanation:** Note that 070 is not a valid number, because it has leading zeroes.

**Example 2:**

**Input:** n = 2, k = 1
**Output:** [10,12,21,23,32,34,43,45,54,56,65,67,76,78,87,89,98]

**Constraints:**

- `2 <= n <= 9`
- `0 <= k <= 9`

```python
class Solution:
    """
    The solution is an optimized backtracking / DFS generation approach
    A lot of people think backtracking always requires:
    - path.append()
    - path.pop()
    that is comon, but not required.
    
    WHAT DEFINES BACKTRACKING?
    backtracking fundamentally means:
    1. build a partial solution
    2. explore recursively
    3. abandon invalid branches
    4. try other possibilities
    and this soution does exactaly that.
    
    Why no pop()?
    num * 10 + next_digit: each recursive call gets its own independent number.
    there is no choose or not choose, if yes, then, needs the undo.
    but for this solution, it provides the possible candidates, to choose them and abandon them(invalid branches). so, it only has choose and abandon.
    """
    def numsSameConsecDiff(self, n: int, k: int) -> List[int]:
        """
        the k is known, then, to build the answer, instead of for loop to get and compare. 

        """
        ans = []
        def backtrack(num, length):
            if length = n:
                ans.append(num)
                return

            prev_digit = num % 10
            # actively to find the possible answers by + or - k
            # called: pruning during generation
            next_digits = set([
                prev_digit + k,
                prev_digit - k,
            ])

            for next_digit in next_digits:
                if 0 <= next_digit <= 9:
                    # next level, from n digits to n + 1 digits
                    backtrack(num * 10 + next_digit, length + 1)

        for start_digit in range(1,10):
            backtrack(start_digit, 1)

        return ans




```
