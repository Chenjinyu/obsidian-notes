# Problem
There are `n` cities. Some of them are connected, while some are not. If city `a` is connected directly with city `b`, and city `b` is connected directly with city `c`, then city `a` is connected indirectly with city `c`.

A **province** is a group of directly or indirectly connected cities and no other cities outside of the group.

You are given an `n x n` matrix `isConnected` where `isConnected[i][j] = 1` if the `ith` city and the `jth` city are directly connected, and `isConnected[i][j] = 0` otherwise.

Return _the total number of **provinces**_.

**Example 1:**
![](assets/M%20-%200547.%20Number%20of%20Provinces/file-20260404033850042.png)
**Input:** `isConnected = [[1,1,0],[1,1,0],[0,0,1]]`
**Output:** 2

**Example 2:**
![](assets/M%20-%200547.%20Number%20of%20Provinces/file-20260404033905199.png)
**Input:** `isConnected = [[1,0,0],[0,1,0],[0,0,1]]`
**Output:** 3

**Constraints:**
- `1 <= n <= 200`
- `n == isConnected.length`
- `n == isConnected[i].length`
- `isConnected[i][j]` is `1` or `0`.
- `isConnected[i][i] == 1`
- `isConnected[i][j] == isConnected[j][i]`

# Step 3 - Think about Optimization

Here, we pass the integer label of the node. This is a concept that you will need to master - with graphs, the graph only "exists" as an idea. It is up to you to implement a method of representing the nodes and edges and traversing over them.

### 1. Stack DFS deal with adjacency matrix directly
compare with: [[../Coding/Data Structure and Algorithms/5 - Trees and Graphs/Graphs/Different Graph Representations|Different Graph Representations]] 3.2. Adjacency Matrix Graph Traversal, the solution just a simple traversal from a single node. it does not know how many graphs exist. 
but below solution will loop all rows to find multi graphs.
```python
class Solution:
	def findCircleNum(self, isConnected: List[List[int]]) -> int:
		"""
		TIME Complexity: O(n^2)
		the loop starts from the outer for loop which is the last one for loop where calls dfs(i)
		so, outer for loop -> visits each vertex once = O(n), inside of each dfs
		dfs inner for loop -> scan entire row for each popped vertex = O(n)
		each vertex is poped exactly once (vistied guards this)
		
		total = O(n) × O(n) = O(n²)
		
		This is unavoidable with an adjacency matrix - even if a vertex has no neighbors, 
		you still scan all `n` columns to find out.
		
		SPACE Complexity: O(n)
		`visited` set:  O(n)         at most n vertices
		`stack`:        O(n)         at most n vertices queued
		`provinces`counter:    O(1). single integer
		"""
		num_of_prov = 0
		visited = set() # <- defined OUTSIDE dfs, shared globally
		n = len(isConnected)
		
		def dfs(node):
			stack = [node]
			visited.add(node)
			
			# after a while loop, all passed nodes are marked as visited.
			# this is the while loop purpose.
			while stack:
				curr = stack.pop()
				for neighbor in range(n):
					if isConnected[curr][neighbor] == 1 and neighbor not in visited:
						visited.add(neighbor)
						stack.append(neighbor)
		# the trick thing here is: the row represents each node in adjacent matrix. 
		for i in range(n): # i is the index of row of matrix, also is the graph node, and isConnected[i] is the neighbors if value is 1.
			if i not in visited: # using visited to check how many graph nodes will be added into visited.
				dfs(i) # <- once a vertex is visited, it NEVER gets poped again.
				num_of_prov += 1
		
		return num_of_prov
# The key insight:
#    The outer `for i` loop is just a **launcher** — it finds unvisited starting points. 
#    The actual work happens inside dfs, and the shared `visited` set ensures the total work 
#    across all launches is still just n pops.
isConnected = [[1,0,0],[0,1,0],[0,0,1]]

```

### 2. Stack DFS deal with adjacency list after convert
```python
from collections import defaultdict

class Solution:
    def findCircleNum(self, isConnected: List[List[int]]) -> int:
        def dfs(node):
            for neighbor in graph[node]:
                # the next 2 lines are needed to prevent cycles
                if neighbor not in seen:
                    seen.add(neighbor)
                    dfs(neighbor)
        
        # build the graph with adjacency list
        n = len(isConnected)
        graph = defaultdict(list)
        for i in range(n):
            for j in range(i + 1, n):
                if isConnected[i][j]:
                    graph[i].append(j)
                    graph[j].append(i) # symmtric metrix for undirected graph
        
        seen = set()
        ans = 0
        
        for i in range(n):
            if i not in seen:
                # add all nodes of a connected component to the set
                ans += 1
                seen.add(i)
                dfs(i)
        
        return ans
```

### 3. Union-Find (Disjoint Set Union, DSU) solution
Same pattern
- [[M - 0323. Number of Connected Components in an Undirected Graph]]
```python
class Solution:
    def findCircleNum(self, isConnected: List[List[int]]) -> int:
    """
    Using Union-Find(Disjoin Set Union)
    """
    n = len(isConnected) # the problem said it has n nodes
    parent = list(range(n))
    rank = [1] * n

    def find(x):
        if parent[x] != x:
            parent[x] = find(parent[x])
        return parent[x]


    def union(a, b):
        root_a, root_b = find(a), find(b)
		# means the parent is itself, wont count.
        if root_a == root_b:
            return 0

        if rank[root_a] < rank[root_b]: # if root_b rank is bigger means the root_b is the parent.
            parent[root_a] = root_b
            rank[root_b] += rank[root_a]
        else:
	        # otherwise, use the first one node as the parent
            parent[root_b] = root_a
            rank[root_a] += rank[root_b]

        return 1

    component = n

    for i in range(n):
        for j in range(i + 1, n): # upper triangle only, avoid duplicates
            component -= union(i, j)
    return component

```
