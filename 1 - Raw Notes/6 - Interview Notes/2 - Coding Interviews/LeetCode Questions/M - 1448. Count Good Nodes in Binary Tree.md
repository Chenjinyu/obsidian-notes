# Problem
Given a binary tree `root`, a node _X_ in the tree is named **good** if in the path from root to _X_ there are no nodes with a value _greater than_ X.
Return the number of **good** nodes in the binary tree.

**Example 1:**
```text
        3
       /  \
      1    4
     /    /  \
    3    1    5
```
**Input:** root = [3,1,4,3,null,1,5]
**Output:** 4
**Explanation:** Nodes in blue are **good**.
Root Node (3) is always a good node.
Node 4 -> (3,4) is the maximum value in the path starting from the root.
Node 5 -> (3,4,5) is the maximum value in the path
Node 3 -> (3,1,3) is the maximum value in the path.

**Example 2:**
```text
        3
       /
      3
     / \
    4   2
```
**Input:** root = [3,3,null,4,2]
**Output:** 3
**Explanation:** Node 2 -> (3, 3, 2) is not good, because "3" is higher than it.

**Example 3:**
**Input:** root = [1]
**Output:** 1
**Explanation:** Root is considered as **good**.

```python
# Definition for a binary tree node.
# class TreeNode:
#     def __init__(self, val=0, left=None, right=None):
#         self.val = val
#         self.left = left
#         self.right = right
class Solution:
    def goodNodes(self, root: TreeNode) -> int:
        """
        First, this should be the DFS traversal
        Second, pre-order to read the current node first
        third, using the stack and stores the good nodes count
        """
        if not root: return 0
        # if not root.left and not root.right: return 1
        
        curr_count = 0
        stack = [(root, float('-inf'))] # current node, previous node value, and count
        while stack:
	        node, prev_max = stack.pop()
	        if node.val >= prev_max: 
		        curr_count += 1 # always updates the same variable
		    prev_max = max(node.val, prev_max) # outside of the if condition, the max val should be checked with every node.
	         
	        if node.right: stack.append((node.right, prev_max))
	        if node.left: stack.append((node.left, prev_max))
	        
	    return curr_count
        
```

# Step 5 - Re implement from scratch. 
```python
"""
The recursive solution here will slightly faster than the stack, due to less tuple packing/unpacking overhead.
"""
def goodNodes(self, root: TreeNode) -> int:
    def dfs(node, prev_max):
        if not node:
            return 0
        
        is_good = 1 if node.val >= prev_max else 0
        new_max = max(node.val, prev_max)
        return is_good + dfs(node.left, new_max) + dfs(node.right, new_max)
    
    return dfs(root, float('-inf'))
```

## Time and Space complexity
#### **Recursive solution:**

|Complexity|Reason|
|---|---|---|
|Time|O(n)|visits every node exactly once|
|Space|O(h)|call stack depth = tree height|

Where `h` is the tree height — O(log n) for balanced tree, O(n) worst case for skewed tree.

#### **Iterative solution:**

|Complexity|Reason|
|---|---|---|
|Time|O(n)|visits every node exactly once|
|Space|O(w)|stack holds at most one full level of nodes|

Where `w` is the maximum width of the tree — O(n) worst case for a complete tree, O(1) for a skewed tree.

---

**Comparison:**

|                  | Recursive         | Iterative          |
| ---------------- | ----------------- | ------------------ |
| Time             | O(n)              | O(n)               |
| Space worst case | O(n) skewed tree  | O(n) complete tree |
| Space best case  | O(log n) balanced | O(1) skewed        |

In practice they are equivalent. The difference is just **which tree shape** triggers the worst case space — recursive suffers on skewed trees, iterative suffers on wide trees.
