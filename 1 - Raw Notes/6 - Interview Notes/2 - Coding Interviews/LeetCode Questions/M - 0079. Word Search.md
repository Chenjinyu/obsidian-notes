# Problem
Given an `m x n` grid of characters `board` and a string `word`, return `true` _if_ `word` _exists in the grid_.
The word can be constructed from letters of sequentially adjacent cells, where adjacent cells are horizontally or vertically neighboring. The same letter cell may not be used more than once.

**Example 1:**
![](https://assets.leetcode.com/uploads/2020/11/04/word2.jpg)

**Input:** board = `[["A","B","C","E"],["S","F","C","S"],["A","D","E","E"]]`, word = "ABCCED"
**Output:** true

**Example 2:**
![](https://assets.leetcode.com/uploads/2020/11/04/word-1.jpg)
**Input:** board = `[["A","B","C","E"],["S","F","C","S"],["A","D","E","E"]]`, word = "SEE"
**Output:** true

**Example 3:**
![](https://assets.leetcode.com/uploads/2020/10/15/word3.jpg)

**Input:** board = `[["A","B","C","E"],["S","F","C","S"],["A","D","E","E"]]`, word = "ABCB"
**Output:** false

**Constraints:**
- `m == board.length`
- `n = board[i].length`
- `1 <= m, n <= 6`
- `1 <= word.length <= 15`
- `board` and `word` consists of only lowercase and uppercase English letters.

**Follow up:** Could you use search pruning to make your solution faster with a larger `board`?

class Solution:
	"""
	The issues for the solution:
	1. the direction should down, up, left and right.
	2. w should not be a global parameter across recursion branches, each recursive path needs its own character index. like the dfs traversal, each node has its own value need to be calcuated.
	3. [IMPORTANT]the current cell itself should be marked visted, NOT the next cell before recurision.
	4. backtrack(0,0, word[w]), the word may start anywhere on the board. must try every cell.
	"""
    def exist(self, board: List[List[str]], word: str) -> bool:
        rows, cols = len(board), len(board[0])
        # the search can go down and right, should not go left and up.
        visited = [[False] * cols for _ in range(rows)]
        w, ans = 0, 0 # w should not be a global across recursion branches.  each recurisve path needs its own character index.
        def backtrack(row, col, target_char):
            nonlocal w, ans
            if row == rows:
                return

            for col in range(cols):
                
                if w == len(word) - 1:  # find it, so that the w index is word len
                    ans += 1
                    return
                if board[row][col] == target_char:
                    w += 1
                    target_char = word[w]

                if 0 <= row < rows - 1 and visited[row + 1][col] == False:
                    visited[row + 1][col] = True
                    backtrack(row + 1, col, target_char) # towards right
                    visited[row + 1][col] = False
                if 0 <= col < cols - 1 and visited[row][col + 1] == False:
	                visited[row][col + 1] = True
                    backtrack(row, col + 1, target_char) # towards bottom.
                    visited[row][col + 1] = False

        backtrack(0,0, word[w])
        return ans
```

class Solution:
	"""
	when i was doing adjancey list to search the neighbors, or the matrix with 2D array, check the closest, costlessest path, there is no UNDO, every next step knows.
	for this problem, I have to check when choose and not choose(undo) 
	
	"""
    def exist(self, board: List[List[str]], word: str) -> bool:
        rows, cols = len(board), len(board[0])
        
        def backtrack(row, col, index):
            if index == len(word): # index reaches the last word of word
                return True

            # out of boundary or mismatch
            if (
                row < 0 or row >= rows or 
                col < 0 or col >= cols or 
                board[row][col] != word[index]
            ): 
                return False
            
            # temprarily mark visited
            temp = board[row][col]
            board[row][col] = '#' # choose, board[row][col] never = '#'

            is_found = ( # backtrack
                backtrack(row + 1, col, index + 1) or  # right
                backtrack(row, col + 1, index + 1) or  # down
                backtrack(row - 1, col, index + 1) or  # left
                backtrack(row, col - 1, index + 1)     # up
            )
            board[row][col] = temp # undo

            return is_found

        # try every cell to check the start postion for word
        for row in range(rows):
            for col in range(cols):
                if backtrack(row, col, 0): return True

        return False 
```
