# Problem
Given the `root` of a binary tree, return _the length of the **diameter** of the tree_.
The **diameter** of a binary tree is the **length** of the longest path between any two nodes in a tree. This path may or may not pass through the `root`.
The **length** of a path between two nodes is represented by the number of edges between them.

**Example 1:**
```text
    1
   / \
  2   3
 / \
4   5
```
**Input:** root = [1,2,3,4,5]
**Output:** 3
**Explanation:** 3 is the length of the path [4,2,1,3] or [5,2,1,3].

**Example 2:**
**Input:** root = [1,2]
**Output:** 1

Example 3:
input:
```text
                1                        1 
               / \                    /     \
              2   3                  2       3   
             / \                    / \     / \ 
            4   5                  4   5   6   7
           /   /                  /    /     \
          8   9                  8    9      12
         /   /                  /    /
        10  11                 10   11      
```
this case, the max path is not pass through the root.

**Constraints:**
- The number of nodes in the tree is in the range `[1, 104]`.
- `-100 <= Node.val <= 100`

## 1. Using Stack as solution
1. In this case, it use two global vars, due to the observation of  [[Observations/DFS/A Universal Principle for tree DFS traversal|A Universal Principle for tree DFS traversal]], the global vars are assigned the calculated value from the while loop, and in each node, it carries current ROOT-TO-NODE info, and every node has it owns path, each node carries their own value.
2. The iterative version needs postorder (`visited` flag trick) because height of children must be known before processing the parent

```python
# Definition for a binary tree node.
# class TreeNode:
#     def __init__(self, val=0, left=None, right=None):
#         self.val = val
#         self.left = left
#         self.right = right
class Solution:
    def diameterOfBinaryTree(self, root: Optional[TreeNode]) -> int:
	    """
	    this uses the Post-order, because the height of children must be known
	    before processing the parent.
	    the diameter at any node is left_height + right_height, so must know
	    the height of both children before you can compute anything at the current node.
	    """
        if not node: return 0
        height = {}
        ans = 0
        stack = [(root, False)] # node, if visited.
        
        while stack:
            node, visited = stack.pop()
			# visited flag,is a deferred(延迟) processing trick.
			# because visited flag allow the traversal is Post-order
			# in the else branch, it always push new nodes with false, and false flag will add its own children 
			# so `visited=False` means "I've seen this node, but not processed it."
			# and `visited=True` means _"my children are done, process me now."_
            if visited is True: # the purppse is to read children first.
	            # children already done, now process current node.
                left_h = height.get(node.left, 0) # does not exist, then return 0
                right_h = height.get(node.right, 0)
                # for current node, it can get the height from left and from right
                # and ans always store current maximum
                ans = max(left_h + right_h, ans)
                # max height from left_h and right_h
                # each node has its own path, the height will be differ.
                height[node] = max(left_h, right_h) + 1
            else:
                # then, current node is visited, revisit for children
                # Post-order, because parent append first, then pop last.
                stack.append((node, True)) 
                # this is dfs, it will apend the node until the node is None.
                if node.right: stack.append((node.right, False)) 
                if node.left: stack.append((node.left, False))
        return ans
```


## 2. using recursive
```python
# Definition for a binary tree node.
# class TreeNode:
#     def __init__(self, val=0, left=None, right=None):
#         self.val = val
#         self.left = left
#         self.right = right
class Solution:
    def diameterOfBinaryTree(self, root: Optional[TreeNode]) -> int:
	    """
	    this also is a post-order traversal.
	    because ans = max(ans, left + right) which read left and right first
	    """
	    ans = 0
	    
	    def dfs(node):
		    if not node: return 0
		    nonlocal ans
		    left = dfs(node.left)
		    right = dfs(node.right)
		    
		    ans = max(ans, left + right) # diameter through current node
		    return max(left, right) + 1 # height returned to parent, since return to parent, then the parent node is the last one to read
		return ans
```
