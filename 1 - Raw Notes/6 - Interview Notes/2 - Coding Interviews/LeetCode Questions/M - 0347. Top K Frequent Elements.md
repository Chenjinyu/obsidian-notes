Time Complexity of heapq.nlargest(): O(n log k)
`nlargest` does NOT heapify the entire iterable. Instead it:
1. Builds a **min-heap of size k** from the first k elements — **O(k)**
2. Iterates over the **remaining n-k elements** one by one:
    - If current element > heap top → pop and push → **O(log k)**
    - Otherwise skip
3. Returns the k elements
--> n iterations × O(log k) per operation = **O(n log k)**
Think of it as a **sliding window of top-k candidates** — you maintain a small heap of size k as a "filter" while scanning through all n elements. The heap stays small, the scan is long.

# Problem
Given an integer array `nums` and an integer `k`, return _the_ `k` _most frequent elements_. You may return the answer in **any order**.

**Example 1:**
**Input:** nums = [1,1,1,2,2,3], k = 2
**Output:** [1,2]

**Example 2:**
**Input:** nums = [1], k = 1
**Output:** [1]

**Example 3:**
**Input:** nums = [1,2,1,2,1,2,3,1,3,2], k = 2
**Output:** [1,2]

**Constraints:**
- `1 <= nums.length <= 105`
- `-104 <= nums[i] <= 104`
- `k` is in the range `[1, the number of unique elements in the array]`.
- It is **guaranteed** that the answer is **unique**.

**Follow up:** Your algorithm's time complexity must be better than `O(n log n)`, where n is the array's size.

class Solution:
	"""
	Time Complexity: O(n log k)
	- Counter(nums): O(n)
	- heapq.nlargest(k, iterable, compare_key): O(n log k) - it maintains a min-heap of size k while iterating over all n unique elememts.
	  - log k here, is like heappop to get the value before compare with the whole nums
	  
	Space Complexity: O(n)
	- Counter: stores at most n unique element: O(n)
	- nlargest: maintains a heap of size k internally: O(k)
	- output list of size k: O(k)
	"""
    def topKFrequent(self, nums: List[int], k: int) -> List[int]:
        if not nums:
            return []
        frequency = Counter(nums)
        return heapq.nlargest(n=k, iterable=frequency.keys(), key=frequency.get)
        # iterable: from which you want to extract the largest elements.
        # key: A function that serves as a key for comparing elements.
        # OR
        # the nums_tops is a list of tuple like [(3, 4), (1, 2)], it's not dict.
        nums_tops = heapq.nlargest(k, frequency.items(), key=lambda x: x[1])
        return [item[0] for item in nums_tops]
        # return int(nums_tops.keys()) # does not work, because the nums_tops is list of tuple
