# Problem
Given a string containing digits from `2-9` inclusive, return all possible letter combinations that the number could represent. Return the answer in **any order**.
A mapping of digits to letters (just like on the telephone buttons) is given below. Note that 1 does not map to any letters.

![300](https://assets.leetcode.com/uploads/2022/03/15/1200px-telephone-keypad2svg.png)

**Example 1:**
**Input:** digits = "23"
**Output:** ["ad","ae","af","bd","be","bf","cd","ce","cf"]

**Example 2:**
**Input:** digits = "2"
**Output:** ["a","b","c"]

**Constraints:**
- `1 <= digits.length <= 4`
- `digits[i]` is a digit in the range `['2', '9']`.

# Step 3 - Think about Optimization
```python
class Solution:
	"""
	Compare with [[M - 0077. Combinations]], the logic is same. 
	the combinations leetcode problem is getting the subsquence idx.
	current problem is getting the next letters by moving index.
	"""
    def letterCombinations(self, digits: str) -> List[str]:
        """
        3 ^ digits
        Time Complexity: worse case if choose 7 or 9: O (n * 4 ^ n)
	        - the backtrack: O(3 ^ len(digits)) or O(4 ^ len(digits))
	        - "".join(path): O(3) or O(4)
        """
        n = len(digits)
        if not n: return []

        digits_dict = {
            '2': 'abc',
            '3': 'def',
            '4': 'ghi',
            '5': 'jkl',
            '6': 'mno',
            '7': 'pqrs',
            '8': 'tuv',
            '9': 'wxyz'
        }
        
        ans = []

        def backtrack(index, path):
            if len(path) == n:
                ans.append("".join(path))
                return

            curr_digit = digits[index]
            chars = digits_dict[curr_digit]

            for ch in chars:
                path.append(ch)
                backtrack(index + 1, path)
                path.pop()

        backtrack(0, [])
        return ans

# Input: digits = "23"
# Output: ["ad","ae","af","bd","be","bf","cd","ce","cf"]
```
