# Problem

You are given an array of integers `nums`, there is a sliding window of size `k` which is moving from the very left of the array to the very right. You can only see the `k` numbers in the window. Each time the sliding window moves right by one position.
Return _the max sliding window_.

**Example 1:**
**Input:** nums = [1,3,-1,-3,5,3,6,7], k = 3
**Output:** [3,3,5,5,6,7]
**Explanation:** 
Window position                Max
---------------               -----
[1  3  -1] -3  5  3  6  7       **3**
 1 [3  -1  -3] 5  3  6  7       **3**
 1  3 [-1  -3  5] 3  6  7       5
 1  3  -1 [-3  5  3] 6  7       **5**
 1  3  -1  -3 [5  3  6] 7       **6**
 1  3  -1  -3  5 [3  6  7]      **7**

**Example 2:**
**Input:** nums = [1], k = 1
**Output:** [1]

**Constraints:**
- `1 <= nums.length <= 10^5`
- `-10^4 <= nums[i] <= 10^4`
- `1 <= k <= nums.length`

# using sliding window
class Solution:
	# Time Limit Exceeded
    def maxSlidingWindow(self, nums: List[int], k: int) -> List[int]:
	    # time complexity: O(k) * O(n) = O(n*k)
        ans = []

        for left in range(len(nums) - k + 1): # O(k)
	        # max() is O(k)
            ans.append(max(nums[left: k + left])) # every window needs to recomputing the max, even the window only changs by one element each step

        return ans
```

	   for example: queue has [8, 5, 3, 2], now a new element value is 4. the monotonic decreasing queue will do:

from collections import deque
# Why stores the nums's index in the queue, 
# because the problem is asking the gap between two items to get how long the weather will get warmer
class Solution:
    def maxSlidingWindow(self, nums: List[int], k: int) -> List[int]:
        output = []
        queue = deque()
        for i in range(len(nums)):
            # maintain monotonic decreasing.
            # if current/coming value is greater than the last one in queue, 
            # then, last one in queue pop out
            while queue and nums[queue[-1]] < nums[i]:
                queue.pop() # pop out from right

            queue.append(i)

            # queue[0] is the index of the maximum element.
            # if queue[0] + k == i, then it is outside the window
            # here using the max value's index + k, means the left almost boundary has to 
            # move to next. so, popleft(), eg. [1,3,-1,-3,5,3,6,7]. index 1 has to popleft()
            # because the code needs to calcuate new max in coming sub array: [-1, -3, 5]
            if queue[0] + k == i: # queue[0] < i - k + 1:
                queue.popleft()
            
            # only add to the answer once our window has reached size k
            if i >= k - 1:
                output.append(nums[queue[0]])

        return ans
```

- When need to check the gap between two items, it should store the item's index instead of value.
