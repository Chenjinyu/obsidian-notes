# Problem
You are given an `m x n` integer matrix `matrix` with the following two properties:
- Each row is sorted in non-decreasing order.
- The first integer of each row is greater than the last integer of the previous row.

Given an integer `target`, return `true` _if_ `target` _is in_ `matrix` _or_ `false` _otherwise_.
You must write a solution in `O(log(m * n))` time complexity.

**Example 1:**
![](https://assets.leetcode.com/uploads/2020/10/05/mat.jpg)
**Input:** matrix = `[[1,3,5,7],[10,11,16,20],[23,30,34,60]]`, target = 3
**Output:** true

**Example 2:**
![](https://assets.leetcode.com/uploads/2020/10/05/mat2.jpg)
**Input:** matrix = `[[1,3,5,7],[10,11,16,20],[23,30,34,60]]`, target = 13
**Output:** false

**Constraints:**
- `m == matrix.length`
- `n == matrix[i].length`
- `1 <= m, n <= 100`
- `-104 <= matrix[i][j], target <= 104`

class Solution:
    def searchMatrix(self, matrix: List[List[int]], target: int) -> bool:
        """
        The algorithm has two separate phases:
        1. scan rows:  O(m)
        2. Binary Search inside one row: O(log n)
        The total time complexiy: O(m + log n), 

        You can only drop a term when it's dominated by another term as n → ∞. For example:
        O(m + m) → O(m) ✅ same order
        O(m² + m) → O(m²) ✅ m is dominated by m²
        O(m + log n) → cannot simplify ❌ because m and n are independent variables
        """
        target_row = 0
        # Time Complexity: O(m)
        for idx, nums in enumerate(matrix):
            if target > nums[-1]:
                continue
            else:
                target_row = idx
                break
        
        nums = matrix[target_row]
        left, right = 0, len(nums) - 1

        # O(log n)
        while left <= right:
            mid = (left + right) // 2

            if nums[mid] == target:
                return True
            elif nums[mid] > target:
                right = mid -1
            else:
                left = mid + 1
        return False

# Step 3 - Think about Optimization

This solution is converting the mid to row and col, similar with [[M - 0909. Snakes and Ladders]]
```python
class Solution:
    def searchMatrix(self, matrix: List[List[int]], target: int) -> bool:
        """
        Time Complexity: O(log (m * m))
        """
        rows, cols = len(matrix), len(matrix[0])
        left, right = 0, rows * cols - 1

        while left <= right:
            mid = (left + right) // 2
            # the mid's row and col gets from // and % by cols. 
            r, c = mid // cols, mid % cols

            if matrix[r][c] == target:
                return True
            elif matrix[r][c] > target: 
                right = mid - 1 
            else:
                left = mid + 1
            
        return False

"""
2D matrix: [[1,3,5,7],[10,11,16,20],[23,30,34,60]]
is actually: [1, 3, 5, 7, 10, 11, 16, 20, 23, 30, 34, 60]. this is called row-major order (row by row)
Each row has **`cols` elements**.
So:
- Row 0 → indices 0–3
- Row 1 → indices 4–7
- Row 2 → indices 8–11
## 🧠 Why `r = mid // cols`
Think:
> “How many full rows have I passed?”
Each row has `cols` elements.
So:  r = mid // cols

Example: mid = 5, cols = 4
r = 5 // 4 = 1   # second row

## 🧠 Why `c = mid % cols`
Now:
> “What is the position _inside_ that row?”
c = mid % cols
Example:
c = 5 % 4 = 1   # second column
"""

```
