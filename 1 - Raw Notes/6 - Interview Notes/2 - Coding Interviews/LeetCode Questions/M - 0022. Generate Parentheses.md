# Problem
Given `n` pairs of parentheses, write a function to _generate all combinations of well-formed parentheses_.

**Example 1:**
**Input:** n = 3
**Output:** ["((()))","(()())","(())()","()(())","()()()"]

**Example 2:**
**Input:** n = 1
**Output:** ["()"]

**Constraints:**
- `1 <= n <= 8`

# Step 3 - Think about Optimization
```python
class Solution:
	"""
	This is a classic constrained backtracking problem
	at every step, 
	- add "("
	- add ")"
	1. n's "(", must follow with n's ")"
	2. close_count shoud < open_count, even cannot equal. if equal, then, it will have ()) or ). which is ) cannot be the first or cannot more than current step open_count.
	   
	Compare with other backtracking problem, eg. [[M - 0216. Combination Sum III]] which is depth-first verically
	this solution is only verical by count + 1
	
	"""
    def generateParenthesis(self, n: int) -> List[str]:
        ans = []

        def backtrack(path, open_count, close_count):
            if len(path) == 2 * n:
                ans.append("".join(path))
                return

            # add "("
            if open_count < n:
                path.append("(")
                backtrack(path, open_count + 1, close_count)
                path.pop()
			
			# add ")"
            if close_count < open_count:
                path.append(")")
                backtrack(path, open_count, close_count + 1)
                path.pop()

        backtrack([], 0, 0)
        return ans 
```
