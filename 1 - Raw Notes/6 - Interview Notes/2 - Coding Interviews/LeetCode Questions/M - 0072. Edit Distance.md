# Problem
Given two strings `word1` and `word2`, return _the minimum number of operations required to convert `word1` to `word2`_.
You have the following three operations permitted on a word:

- Insert a character
- Delete a character
- Replace a character

**Example 1:**
**Input:** word1 = "horse", word2 = "ros"
**Output:** 3
**Explanation:** 
horse -> rorse (replace 'h' with 'r')
rorse -> rose (remove 'r')
rose -> ros (remove 'e')

**Example 2:**
**Input:** word1 = "intention", word2 = "execution"
**Output:** 5
**Explanation:** 
intention -> inention (remove 't')
inention -> enention (replace 'i' with 'e')
enention -> exention (replace 'n' with 'x')
exention -> exection (replace 'n' with 'c')
exection -> execution (insert 'u')

**Constraints:**
- `0 <= word1.length, word2.length <= 500`
- `word1` and `word2` consist of lowercase English letters.

# Step 3 - Think about Optimization
```python
class Solution:
    def minDistance(self, word1: str, word2: str) -> int:
        """
        Tabulation: Solve subproblems first, store their results in a table
        and build up to the final answer step by step
        """
        m, n = len(word1), len(word2) # rows, cols

        # dp stores the number of operations
        dp = [[0] * (n + 1) for _ in range(m + 1)]

        # base cases
        # when word1 = "", how many operations convert to word2
        # the word1 needs to insert the incremental operations(insert) to align with word2 in each step
        for i in range(m + 1):
            dp[i][0] = i
        
        # when word2 = "", how maby operations(delete) convert from word1 to word2
        for j in range(n + 1):
            dp[0][j] = j

        for i in range(1, m + 1): # word1, the target going to modification
            for j in range(1, n + 1): # word2
                if word1[i-1] == word2[j-1]:
                    # since they are the same, there is no any operations
                    # the curr step equals the prev step
                    dp[i][j] = dp[i - 1][j - 1]
                else:
                    # subproblem, this is the place need to think about at the first time
                    # getting the min from the next operation by insert/delete/replace
                    # dp[i-1][j-1] is current.
                    dp[i][j] = min(
                        dp[i][j-1], # insert - from word1/target, its inserted a new char(takes one operation), but the j stays the same, so for j position, here is no changes
                        dp[i-1][j], # delete - from word1/target, the position still the same, because it deletes one character, for the next operation, for the i there is no changes. but for j, it moves to next j.
                        dp[i-1][j-1] # replace - after replace operation, both positions of word1 and word2 are stay the same.
                    ) + 1
		# the current position is [i-1][j-1], for the next operation, i want to choose delete, delete it from word1, then the position to point to the next character has no change, for the word2, has move to j. 
        return dp[m][n]
```
