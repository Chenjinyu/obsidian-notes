# Problem
Given the `root` of a binary tree, return _the zigzag level order traversal of its nodes' values_. (i.e., from left to right, then right to left for the next level and alternate between).

**Example 1:**
![200](assets/M%20-%200103.%20Binary%20Tree%20Zigzag%20Level%20Order%20Traversal/file-20260330232344288.png)
**Input:** root = [3,9,20,null,null,15,7]
**Output:** [[3],[20,9],[15,7]]

**Example 2:**
**Input:** root = [1]
**Output:** [[1]]

**Example 3:**
**Input:** root = []
**Output:** []

**Constraints:**
- The number of nodes in the tree is in the range `[0, 2000]`.
- `-100 <= Node.val <= 100`

### correct solution
```python
# Definition for a binary tree node.
# class TreeNode:
#     def __init__(self, val=0, left=None, right=None):
#         self.val = val
#         self.left = left
#         self.right = right
class Solution:
    def zigzagLevelOrder(self, root: Optional[TreeNode]) -> List[List[int]]:
        ans = []
        queue = deque([root])
        node_level = 0
        while queue:
            
            sub_nodes = []
            for _ in range(len(queue)):
                node = queue.popleft()
                if not node: continue
                sub_nodes.append(node.val)
                # always natural order
                queue.append(node.left)  
                queue.append(node.right)
            if sub_nodes: 
                if node_level % 2 == 1: 
	                # reverse only the output, not the queue
                    sub_nodes.reverse()
                ans.append(sub_nodes)
            node_level += 1
        return ans
```
