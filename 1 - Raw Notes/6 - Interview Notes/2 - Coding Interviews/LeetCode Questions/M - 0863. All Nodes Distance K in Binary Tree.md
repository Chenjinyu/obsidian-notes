### Mental Model
- Tree: directed form parent -> child (structurally)
	- Post-order: good for height (downward only)
	- In-order: just a visiting order, no distance meaning.
	- so, traversals do not naturally represent distance from an arbitrary node. 
- Traversals: ways to visit all nodes along that directed path
- BFS for distance: <span style="color:red">treat tree as undirected graph</span>, so you can move in both directions freely

### The right way to think (step by step)
-When you read the problem:
#### Step 1: Identify the starting point
> target node
#### Step 2: Identify the requirement
> nodes at distance K
#### Step 3: Ask:
> “Is this a shortest path / level problem?”
👉 YES → BFS
#### Step 4: Ask:
> “Can I move freely in all needed directions?”
👉 NO → (tree only goes down)
#### Step 5: Fix the structure
👉 Convert to graph (add parent links)

# Problem

Given the `root` of a binary tree, the value of a target node `target`, and an integer `k`, return _an array of the values of all nodes that have a distance_ `k` _from the target node._
You can return the answer in **any order**.

**Example 1:**
![300](assets/M%20-%200863.%20All%20Nodes%20Distance%20K%20in%20Binary%20Tree/file-20260408021805783.png)
**Input:** root = [3,5,1,6,2,0,8,null,null,7,4], target = 5, k = 2
**Output:** [7,4,1]
Explanation: The nodes that are a distance 2 from the target node (with value 5) have values 7, 4, and 1.

**Example 2:**
**Input:** root = [1], target = 1, k = 3
**Output:** []

**Constraints:**
- The number of nodes in the tree is in the range `[1, 500]`.
- `0 <= Node.val <= 500`
- All the values `Node.val` are **unique**.
- `target` is the value of one of the nodes in the tree.
- `0 <= k <= 1000`

```python
# Definition for a binary tree node.
# class TreeNode:
#     def __init__(self, x):
#         self.val = x
#         self.left = None
#         self.right = None
from collections import deque

class Solution:
    def distanceK(self, root: TreeNode, target: TreeNode, k: int) -> List[int]:
        # step 1: build paremt map
        parent_dict = {}
		
		# pre-order dfs traversal
        def dfs(node, parent=None):
            if not node: return
            parent_dict[node] = parent
            dfs(node.left, node)
            dfs(node.right, node)

        dfs(root) # the parent_dict stores all the chile -> parent map

        # Step 2: BFS form target
        queue = deque([target])
        visited = set([target])
        distance = 0

        while queue:
	        # in BFS, the queue always contains all nodes at the current distance from the starting point
	        # distance == 2: queue contains all nodes 2 steps away
	        # are you remember, for the BFS, each loop the queue wil keep the next level of nodes
            if distance == k:
                return [node.val for node in queue]

            for _ in range(len(queue)):
                node = queue.popleft()
				
				# Not only the child back to pranet is the neighbor
				# also the left and right. 
                for neighbor in (node.left, node.right, parent_dict[node]):
                    if neighbor and neighbor not in visited:
                        visited.add(neighbor)
                        queue.append(neighbor)

            distance += 1
        return []

```
