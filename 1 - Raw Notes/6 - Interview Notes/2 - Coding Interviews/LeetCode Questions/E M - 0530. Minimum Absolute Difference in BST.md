# Problem
Given the `root` of a Binary Search Tree (BST), return _the minimum absolute difference between the values of any two different nodes in the tree_.
**Example 1:**
![200](assets/E%20M%20-%200530.%20Minimum%20Absolute%20Difference%20in%20BST/file-20260331015932163.png)
**Input:** root = [4,2,6,1,3]
**Output:** 1

**Example 2:**

**Input:** root = [1,0,48,null,null,12,49]
**Output:** 1

**Constraints:**
- The number of nodes in the tree is in the range `[2, 104]`.

# Step 3 - Think about Optimization

### 1. recursive
```python
# Definition for a binary tree node.
# class TreeNode:
#     def __init__(self, val=0, left=None, right=None):
#         self.val = val
#         self.left = left
#         self.right = right
class Solution:
    def getMinimumDifference(self, root: Optional[TreeNode]) -> int:
        """
        In-Order, left -> node -> right.
        Since its BST, the min value should between two adjacent elements.
        the node's left is adjacent with node's parent. check the description on page top.
        """
        self.prev = None # it cannot be 0, because if the first node is 1, then the min value is 1, it's not correct. for the tree only has two nodes: [1,10], then, the min should be 10, not the 1 from 1 - 0
        self.min_diff = float('inf') # this can NOT be 0, becuase it to get the min, the 0 will always be the min for two nodes distance

        def dfs(node):
            # in recursive, it should return, in stack should continue
            if not node: return 

            dfs(node.left)
            # at this point, self.prev is the in-order predecessor.
            if self.prev is not None:
	            # since its in-order traversal, the node's left is adjacent with node's parent.
                self.min_diff = min(self.min_diff, node.val - self.prev)
            self.prev = node.val

            dfs(node.right)


        dfs(root)
        return self.min_diff
```

### 2.1. Stack with wrong solution: it's not inorder traveral, because the node.left push to stack, it's not read first. but the above recursive does.
```python
# Definition for a binary tree node.
# class TreeNode:
#     def __init__(self, val=0, left=None, right=None):
#         self.val = val
#         self.left = left
#         self.right = right
class Solution:
    def getMinimumDifference(self, root: Optional[TreeNode]) -> int:
        """
        node -> right -> left.
        """
        self.prev = None
        self.min_diff = float('inf')

        stack = [root]
        while stack:
            node = stack.pop() # <-- it is not read first.

            stack.append(node.left)

            if self.prev is not None:
                self.min_diff = min(self.min_diff, node.val - self.prev)
            self.prev = node.val

            stack.append(node.right)

        return self.min_diff
```
### 2.2 Correct Stack solution
```python
# Definition for a binary tree node.
# class TreeNode:
#     def __init__(self, val=0, left=None, right=None):
#         self.val = val
#         self.left = left
#         self.right = right
class Solution:
    def minDiffInBST(self, root: Optional[TreeNode]) -> int:
        stack = []
        curr = root
        min_diff = float('inf')  # this can NOT be 0, becuase it to get the min, the 0 will always be the min for two nodes distance
        prev = None  # it cannot be 0, because if the first node is 1, then the min value is 1, it's not correct. for the tree only has two nodes: [1,10], then, the min should be 10, not the 1 from 1 - 0
        while stack or curr:
            if curr: # the init curr has root, push root to the bottom of start
	            # and until alll curr.left has been pushed ton stack.
	            # this is the first step
                stack.append(curr)
                curr = curr.left
            else:
	            # after all left nodes pushed to stack
                curr = stack.pop() # pop up the deepest one left node. 
                if prev is not None:
                    min_diff = min(min_diff, curr.val - prev) # no needs abs, becuase the curr.val always greater than prev in BST.
                prev = curr.val
                # there is no stack.append(curr.right)
                # because the append will do in if curr:, and the curr is the curr.right. 
                curr = curr.right 
                
        return min_diff

```
