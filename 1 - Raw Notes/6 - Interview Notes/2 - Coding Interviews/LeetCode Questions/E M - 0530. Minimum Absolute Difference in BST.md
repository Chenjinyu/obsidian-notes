# Problem
Given the `root` of a Binary Search Tree (BST), return _the minimum absolute difference between the values of any two different nodes in the tree_.
**Example 1:**
![200](assets/E%20M%20-%200530.%20Minimum%20Absolute%20Difference%20in%20BST/file-20260331015932163.png)
**Input:** root = [4,2,6,1,3]
**Output:** 1

**Example 2:**
![200](assets/E%20M%20-%200530.%20Minimum%20Absolute%20Difference%20in%20BST/file-20260331015953393.png)
**Input:** root = [1,0,48,null,null,12,49]
**Output:** 1

**Constraints:**
- The number of nodes in the tree is in the range `[2, 104]`.
- `0 <= Node.val <= 105`

**Note:** This question is the same as 783: [https://leetcode.com/problems/minimum-distance-between-bst-nodes/](https://leetcode.com/problems/minimum-distance-between-bst-nodes/)

# Step 3 - Think about Optimization

### 1. recursive
```python
# Definition for a binary tree node.
# class TreeNode:
#     def __init__(self, val=0, left=None, right=None):
#         self.val = val
#         self.left = left
#         self.right = right
class Solution:
    def getMinimumDifference(self, root: Optional[TreeNode]) -> int:
        """
        In-Order, left -> node -> right.
        Since its BST, the min value should between two adjacent elements.
        the node's left is adjacent with node's parent. check the description on page top.
        """
        self.prev = None
        self.min_diff = float('inf') # this can be 0

        def dfs(node):
            # in recursive, it should return, in stack should continue
            if not node: return 

            dfs(node.left)
            # at this point, self.prev is the in-order predecessor.
            if self.prev is not None:
	            # since its in-order traversal, the node's left is adjacent with node's parent.
                self.min_diff = min(self.min_diff, node.val - self.prev)
            self.prev = node.val

            dfs(node.right)


        dfs(root)
        return self.min_diff
```

### Stack with wrong solution: it's not inorder traveral, because the node.left push to stack, it's not read first. but the above recursive does.
```python
# Definition for a binary tree node.
# class TreeNode:
#     def __init__(self, val=0, left=None, right=None):
#         self.val = val
#         self.left = left
#         self.right = right
class Solution:
    def getMinimumDifference(self, root: Optional[TreeNode]) -> int:
        """
        node -> right -> left.
        """
        self.prev = None
        self.min_diff = float('inf') # this can be 0

        stack = [root]
        while stack:
            node = stack.pop() # <-- it is not read first.

            stack.append(node.left)

            if self.prev is not None:
                self.min_diff = min(self.min_diff, node.val - self.prev)
            self.prev = node.val

            stack.append(node.right)

        return self.min_diff
```
