first, this is BST, using inorder can get the nodes in sorted from min to max
<span style="color:orange">An inorder DFS traversal prioritizing left before right on a BST will handle the nodes in sorted order.</span>
```
         7
        / \
       3   9
      / \
     1   6
```
for above BST, the min value should between 7 and 6. from the tree, <span style="color:red">they are not adjacent node, but they are adjacent element in list</span>
the inorder traversal will get the nodes to: [1,3,6,7,9], this is what this problem wants to tell the INORDER with BST.
