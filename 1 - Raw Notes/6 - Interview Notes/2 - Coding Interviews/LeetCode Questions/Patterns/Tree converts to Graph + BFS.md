# Content

Ask yourself:
> “From the target node, how many directions can I move?”

Answer:
- left child ✅
- right child ✅
- parent ❗ (this is the problem)

## 🚨 This is the trigger
Whenever you see:
> “I need to move **up AND down** from a node”

👉 Your brain should immediately go: ```Tree → Graph```

# 🎯 The mental shortcut (memorize this)

### If a problem says:
- distance from a node
- nodes K away
- spread / infection / burning tree
- not restricted to subtree

👉 Then: Use BFS from that node
