# Problem
Given the roots of two binary trees `p` and `q`, write a function to check if they are the same or not.
Two binary trees are considered the same if they are structurally identical, and the nodes have the same value.

**Example 1:**
```text
    1        1
   /  \     /  \
  2    3   2    3 
```
**Input:** p = [1,2,3], q = [1,2,3]
**Output:** true

**Example 2:**
```text
    1    1
   /      \
  2        2
```
**Input:** p = [1,2], q = [1,null,2]
**Output:** false

Example 3:
```text
    1        1
   /  \     /  \
  2    1   1    2 
```
**Input:** p = [1,2,1], q = [1,1,2]
**Output:** false

**Constraints:**
- The number of nodes in both trees is in the range `[0, 100]`.
- `-104 <= Node.val <= 10^4`

### 1. using recursive

```python
# Definition for a binary tree node.
# class TreeNode:
#     def __init__(self, val=0, left=None, right=None):
#         self.val = val
#         self.left = left
#         self.right = right
class Solution:
    def isSameTree(self, p: Optional[TreeNode], q: Optional[TreeNode]) -> bool:
        """
        """
        # in recurisve, return True from one branch doesn't end the whole function.
        if not p and not q: return True 
        if not p or not q: return False
        if p.val != q.val: return False
        return isSameTree(p.left, q.left) and isSameTree(p.right, q.right)
        
```

### 2. using stack
```python
# Definition for a binary tree node.
# class TreeNode:
#     def __init__(self, val=0, left=None, right=None):
#         self.val = val
#         self.left = left
#         self.right = right
class Solution:
    def isSameTree(self, p: Optional[TreeNode], q: Optional[TreeNode]) -> bool:
        """
        It's DFS traversal, with stack
        """
        stack = [(p, q)]
        while stack:
	        a, b = stack.pop()
	        # to cover the case the node a and b are NULL
	        if not a and not b: 
		        continue
		    if not a or not b: # two nodes have diff value, then return False
			    return False
			if a.val != b.val: return False
			
			stack.append((a.left, b.left))
			stack.append((a.right, b.right))
		return True
        
```
