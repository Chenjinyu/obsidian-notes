# Content

Here's a comprehensive breakdown of low-level system design interviews:
---

**What is Low-Level System Design (LLD)?**
```
High-Level Design (HLD)  →  architecture, scalability, distributed systems
Low-Level Design (LLD)   →  classes, objects, design patterns, code structure
```

LLD is about **how you structure your code**, not how you scale your infrastructure.

---

**Common LLD Interview Questions:**

```
1.  Design a Parking Lot
2.  Design a Library Management System
3.  Design an ATM
4.  Design a Chess Game
5.  Design an Elevator System
6.  Design a Hotel Booking System
7.  Design a Shopping Cart
8.  Design a Notification System
9.  Design a URL Shortener (class level)
10. Design an LRU Cache
```

---

**How deep should it be?**

```
Level 1 — Classes and relationships (always required):
  ├── identify all classes/objects
  ├── define attributes and methods
  └── show relationships (inheritance, composition)

Level 2 — Design patterns (expected at mid-senior level):
  ├── which pattern solves this problem
  ├── why you chose it
  └── trade-offs

Level 3 — Code implementation (sometimes required):
  ├── write key classes in actual code
  ├── implement core methods
  └── handle edge cases
```
